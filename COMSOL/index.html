01 입력 파라미터

단위는 µm입니다. 값을 변경하면 자동으로 결과가 갱신됩니다.

클래딩 굴절률은 실리카 Sellmeier로 계산하고 ncore=nclad+Δn를 가정합니다. 실제 G.654.E 제품 단면의 굴절률 프로파일과 동일하다는 의미는 아닙니다.
기준: λ=1.55 µm, a=4.1 µm, Δn=0.005. M8 FEM에서 검증한 12/16/20/24 µm 참조점 사이를 로그 보간합니다. 파라미터를 바꿔 새 FEM을 수행하지 않습니다.
이상적 원형 hollow capillary 근사입니다. 반공진 모세관, nested tube, confinement loss, 표면산란은 포함하지 않습니다.

STEP 01

Python 3.11 설치 및 코드 받기

git clone https://github.com/kimheeseo/LSCNS.git
cd LSCNS
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install numpy scipy matplotlib

Windows PowerShell 기준. Mac/Linux는 python3 -m venv .venv로 생성한 후 .venv/bin/python을 사용하세요.

STEP 02

기존 M7·M8 검증 재실행

.\.venv\Scripts\python.exe COMSOL\run_m7_m8_validation.py

실행하면 모드 분포·메시 수렴·MCF 결합·HCF 기준 계산 결과가 각 screenshots/ 폴더에 PNG, CSV, JSON으로 저장됩니다.

STEP 03

내 광섬유 사양 넣기

from fiber_modes import Fiber, solve_modes, scalar_metrics
fiber = Fiber(wavelength_um=1.55,
              radius_um=4.1,
              delta_n=0.005)
sol = solve_modes(fiber, n=81)
print(scalar_metrics(sol))
