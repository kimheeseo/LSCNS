# 첨부사진 기준 추가 검증 결과보고서

기존 M4 104개 시험과 별도로 사진 기준의 추가 측정을 실제 실행했고 9개 검증 시험이 통과했다. 최초 검사에서는 TM 원통 산란 폭 기준에 실패했으며, 기준을 유지하고 메시를 세분화한 후 통과했다. 사진의 전체 요구사항을 충족한 것으로 확대하지 않는다.

측정 UTC: 2026-10-11T10:41:40.029363+00:00. 첫 측정 118.664432 s, 원통 추가 세분화 및 체적 흡수 측정 10.938340 s. 최종 pytest의 0.143 s는 이미 측정한 JSON을 판정하는 시간이며 FEM 계산 시간이 아니다.

## 독립 체적 흡수 에너지

포트 모드는 ∫p|φ|²=1로 정규화한다. TE에서 A=k₀²∫Im(n²)|u|²/βin, TM에서 A=−∫Im(n⁻²)|∇u|²/βin을 체적 quadrature로 평가한다. A=1−R−T를 기준값으로 쓰지 않았다.

## 최초 실패와 수정

TM 원통 h=.02 µm의 상대 산란 폭 오차는 0.01022463512242111로 1% 기준에 실패했다. 초기 pytest는 7 passed, 1 failed였다. 이는 최저차 P1의 형상·파동 분해능으로 인한 이산화 오차로 판단되며, 기존 세 메시에서 감소하던 오차를 근거로 h=.01 µm로 추가 세분화했다. 오차는 0.002535920726539187로 감소했다. 정확한 폭은 0.22120039029272373 µm, 최종 FEM 폭은 0.22063944363826185 µm이다. 허용오차·형상·굴절률·기준식은 변경하지 않았다. 초기 수치는 photo_validation_initial.json, 초기 실패 XML과 로그에 보존했다.

측정 초기 NumPy int32 JSON 직렬화 오류는 수치 변경 없이 scalar 변환을 추가해 수정했다. 재개 환경에서 Python 3.11과 고정 핵심 패키지를 다시 설치했으며, 기존 104개 결과와 이번 추가 실행의 UTC 및 로그를 구분해 보존했다.

## 검증된 범위

표에 명시한 슬랩·벡터 HE11·M3 층 및 원통·공동·새 파장 직선 M4·흡수층 체적 에너지·직사각형 4모드 직교성, 기존 8채널 S 상반성. 기준값은 독립 닫힌식 또는 Bessel 특성식이고 solver 출력으로 만들지 않았다.

## 검증되지 않은 범위

3D 구 Mie 산란, 모든 임의 굴절률·공진 스펙트럼의 스퓨리어스 배제와 완전성, 임의 bend/taper 정량 정확도, PML 두께·차수 각각의 독립 sweep, 다른 AI 모델 또는 사람에 의한 독립 검토, 실제 COMSOL 대조. 사진의 권고 중 이 항목들은 충족했다고 표시하지 않는다.

## 알려진 한계

HE11은 고굴절률 대비 원형 step-index의 두 편광에 한정한다. 공동 고유모드와 PML·포트 주파수 응답은 서로 다른 구현이다. 이번 분석 모델이 테스트 코드와 해석 oracle을 모두 작성했으므로 식의 구현 독립성을 사람·다른 모델의 독립 검토와 동일시할 수 없다. 통과는 지정한 benchmark와 메시 설정에 한정한다.

## 재현

핵심 환경 Python 3.11.17, NumPy 2.2.6, SciPy 1.15.3, scikit-fem 12.0.2, gmsh 4.14.1.

소스 ZIP의 waveoptics_m4 폴더에서 다음 명령어를 실행한다. gmsh의 Linux 공유 라이브러리 요구사항은 README에 설명한다.

```bash
python -m pip install -e ".[test]"
OPENBLAS_NUM_THREADS=1 python audit/measure_photo.py
OPENBLAS_NUM_THREADS=1 python audit/refine_photo.py
python -m pytest audit/test_photo_criteria.py -q
```

원시 측정은 audit/photo_validation.json, 계약은 audit/CRITERIA.md, 판정은 audit/pytest_photo_final.xml이다. 기존 104개 시험은 results/pytest_nested.xml 및 pytest_regression.xml의 중복 없는 합산이며 results/pytest_final.xml은 파생 합산 파일이다.
