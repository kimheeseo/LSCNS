# LS PremierLink LE125 (G.654.E) — 굽힘손실 2D FEM/PML 계산 및 사양 비교

> **계산일:** 2026-11-03 · **솔버:** [LSCNS 2D scalar P1 FEM + complex PML](../../universal_silica_v01/bending_fem/solver.py) (Git blob `2a6dcccd0f12754e4a6361b05cd0e303beab3366`). **결론: 근사 모델 계산은 완료했으나 수치 수렴 미달, 실제 LE125 제품 사양 합격/불합격 판정 불가.**

## 1. 실제 비교해야 하는 제조사 굽힘 규격

이 보고서의 LE125 참조 데이터는 **사용자가 제공한 LE125 제품 사양표 사진**입니다. ITU-T [G.654.E (2024)](https://www.itu.int/epublications/publication/itu-t-g-654-2024-08-characteristics-of-a-cut-off-shifted-single-mode-optical-fibre-and-cable)에서도 1625 nm의 반경 30 mm·100회 권선 상한을 0.1 dB로 제시합니다.

| 항목 | LE125 제공 사양 |
|---|---:|
| 굽힘 반경 | **R=30 mm** |
| 굽힘 **직경** (FEM 입력 `bend_diameter_mm`) | **60 mm** |
| 권선 수 | **100 turns** |
| 1550 nm 유도 굽힘손실 (100회 합산) | **≤ 0.1 dB** |
| 1625 nm 유도 굽힘손실 (100회 합산) | **≤ 0.1 dB** |
| 권선 1회당 평균 환산 상한 | **≤ 0.001 dB/turn** |

전체 굽힘 구간의 길이는 `100 × 2π × 0.030 m = 18.8496 m`. 굽힘에 의한 추가 손실만을 비교하며, 곧은 섬유의 1550/1625 nm 재료 감쇠·커넥터 손실은 해당 시험 비교에 포함하지 않습니다.

## 2. 사용한 LE125 근사 입력 — 실물 RIP 아님

| 항목 | 수치 | 근거/제한 |
|---|---:|---|
| 프로파일 | Step-index (가정) | 실제 LE125 도핑·트렌치 구조 **미확보** |
| 코어 반경 | 5.5 µm | MFD 대표값 12.5 µm에 맞춰 가정 |
| 코어 굴절률 차 Δn | 0.0034785793846155 | **MFD 보정값, 제조사 설계값 아님** |
| 클래딩 | 순수 실리카 Sellmeier | 실제 복합 코팅·경계 재현하지 않음 |
| 파장 | 1550 / 1625 nm | 제조사 시험과 동일 |
| 굽힘 직경 | 60 mm | **R30 mm**를 직경으로 올바르게 변환 |
| 유효 굴절률 | 복소 고유값 직접 계산 | 2D scalar P1 FEM; full-vector Maxwell 아님 |
| 굽힘 stress | OFF | 실제 GEBT 변형률·응력광학 미구현 |
| FEM 계산창 반폭 | 63 µm | 실제 클래딩 반경 62.5 µm 부근이지만 **클래딩/코팅 계면을 구현한 것이 아님** |
| PML 두께 | 7λ = 10.85 µm / 11.375 µm | 1550 / 1625 nm |
| PML strength | 2; 3차 profile | 외부 흡수층 모델 |
| 가장 미세한 격자 요청 | 0.55 µm | 2D 삼각형 P1 요소, 코어의 곡면 경계는 중심 분류 근사 |

이전의 [LE125 MFD 모델 검증](./G654E_VALIDATION_REPORT.md)에서 MFD 대표값 12.5 µm를 맞춘 가상 Step-index를 사용했습니다. MFD 하나를 맞추는 것만으로 방사 굽힘손실까지 정확히 예측할 수는 없습니다.

## 3. 계산 결과 vs 제조사 규격 — **임시 계산값, 판정 금지**

| 항목 | **1550 nm** | **1625 nm** |
|---|---:|---:|
| 제조사 100 turns 상한 | **≤0.100 dB** | **≤0.100 dB** |
| FEM Re(n_eff) | 1.445733114 | 1.444718869 |
| FEM Im(n_eff) (허수부) | 1.467691×10⁻⁹ | 7.866573×10⁻⁹ |
| FEM 굽힘손실 dB/turn | 0.009740879 | 0.049799788 |
| **FEM ×100 turns 계산값** | **0.974088 dB** | **4.979979 dB** |
| 사양 상한 0.1 dB 대비 수치 비율 | 9.74 | 49.80 |
| **LE125 제품 합불 판정** | **불가 — 모델 미검증** | **불가 — 모델 미검증** |

전파장 `E(z)∝exp(iβz)`, `β=k₀ n_eff`에서 양(+)의 `Im(n_eff)`를 손실로 해석했습니다.

```text
alpha_bend(dB/m) = (20/ln 10)*(2*pi/lambda_m)*Im(n_eff)
L_one_turn(m)    = pi*bend_diameter_m
Loss_100(dB)     = alpha_bend*L_one_turn*100
```

이 모델의 조건에서 제조사 상한 0.1 dB/100 turns를 만족하려면 환산상 `Im(n_eff) ≤1.50673×10⁻¹⁰` (@1550 nm), `≤1.57964×10⁻¹⁰` (@1625 nm)여야 합니다. **이 숫자는 사양을 복소 유효굴절률 단위로 바꾼 계산값이지 LE125 실제 측정값이 아닙니다.**

## 4. 가장 중요한 검증 — 메시·PML 수렴성 실패

### 4.1 메시 h 변화 / PML=7λ 고정 / 창 반폭=63 µm

| 요청 격자 h | 1550 nm / 100 turns | 1625 nm / 100 turns |
|---:|---:|---:|
| 0.90 µm | 1.311595 dB | 5.592939 dB |
| 0.70 µm | 0.921399 dB | 4.928615 dB |
| **0.55 µm** | **0.974088 dB** | **4.979979 dB** |
| **마지막 두 격자 변화율(0.70→0.55)** | **5.409%** | **1.031%** |

### 4.2 PML 두께 변경 / h=0.55 µm 고정 / 창 반폭=63 µm

| PML | 1550 nm / 100 turns | 1625 nm / 100 turns |
|---|---:|---:|
| 6λ | 0.899147 dB | 4.553456 dB |
| **7λ** | **0.974088 dB** | **4.979979 dB** |
| **마지막 두 결과 차이율** | **7.693%** | **8.565%** |

- 화면 진단에서 사용한 **임시 상대변화율 2%** 기준을 **1550 nm 메시와 두 파장 PML 모두 통과하지 못했습니다**. 1625 nm 메시만 1.031%이지만 PML은 실패입니다. 이 2%는 IEEE/ITU/IEC가 규정한 품질 기준이 아닌 **사용자 정의 수치 진단**입니다.
- **계산창 크기 민감도:** 같은 근사 파이버에서 계산창 반폭 22 µm와 63 µm의 1550 nm h≈0.8 계산이 각각 **3.264 dB와 약 1.2 dB/100 turns**, 1625 nm는 **7.873 dB vs 약 5.2 dB/100 turns**로 달라져 **수치 경계 민감도**가 명확합니다.
- **응력 근사 민감도:** h=.9 µm 창=63 µm에서 단순 빔·Poisson 응력광학 proxy를 켜면 1550 nm **1.3116→0.8555 dB**, 1625 nm **5.5929→3.7762 dB**로 달라집니다. **이 proxy는 논문 GEBT가 아니며 정답을 보장하지 않습니다.**

따라서 0.974/4.980 dB는 **독립 제품 예측이나 합격판정 결과로 사용하면 안 됩니다**.

## 5. 왜 실제 LE125 성능과 다르게 나오는가?

1. **실제 굴절률 RIP가 알려지지 않았습니다.** LE125는 MFD≈12.5 µm 규격을 충족하지만 실제 코어 반경, 굴절률 비균일성, trench/depressed-cladding 등의 세부 구조는 이 계산에 적용되지 않았습니다. 가정한 단순 Step-index가 실제보다 누설에 취약할 가능성을 배제할 수 없습니다.
2. **물리적 클래딩/코팅 경계 누락.** 창 반폭 63 µm는 코팅 계면/실제 원통형 외경을 만드는 것이 아닙니다. 사각형 실리카 영역을 PML로 끝내는 계산이며 누설 모드의 허수부에 영향을 줍니다.
3. **스칼라 FEM의 한계.** 실제 편광·벡터 모드 및 기계적 응력(GEBT)을 계산하지 않습니다.
4. **수렴 미달.** 방사손실은 매우 작은 `Im(n_eff)`에 민감하므로 실수부 `n_eff`가 안정적이어도 굽힘손실은 불안정할 수 있습니다.
5. **실제 시험 조건 미반영.** 굽힘 후/전 손실차의 측정 정의, 인가 장력, 코팅, 균일권선, 인가 시간 등에 대한 실험조건이 필요합니다.
