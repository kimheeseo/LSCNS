# STEP 1–2 v0.8.4 — 설계·범위 (2026-11-19)

승인 근거: 사용자가 STEP 0 보고서의 GitHub 업로드와 STEP 1·2 진행을 요청했다.
STEP 3의 고유계/경계 정식화·분류는 이번 변경 범위가 아니다.

## STEP 1

- 기존 A–H 25개 프리셋과 schema_version=1.0.0을 유지한다.
- 수치 타입·필수 재료·가족/변형 조합·기하학 제약을 JSON Schema와 Python에서 검사한다.
- 계산창 밖 공기공을 조용히 생략하지 않고 설계 단계에서 거부한다.
- ring MCF 실제 인접 간격, elliptic PCF 중첩, nested tube 간격, PM 외곽, PBGF 결함 정합을 검사한다.
- 형상 근사/무시되는 파라미터/물성 가정을 프리셋 메타데이터와 진단 JSON으로 노출한다.

## STEP 2

- 기존 geometry.build_mesh 인터페이스를 유지하고 정적 진단 모듈을 추가한다.
- 사용 중인 재료의 n(λ)로 메시 목표를 계산한다. 기존 boundary-refined 정책은 호환 유지하며 벌크 파장 기준 미달을 표시한다.
- 새 wavelength 정책은 전 도메인의 파장당 요소 기준을 적용한다. 대형 메시가 될 수 있으며 기존 벡터 솔버 DOF 상한은 그대로다.
- 곡률당 분할 규칙을 Gmsh 곡률 옵션에 실제 연결한다.
- physical domain·outer boundary·재료 경계·PML interface 라벨, triangle area/edge/aspect·재료별 해상도 통계를 기록한다.
- 원형 annulus 벽은 여러 법선선분과 삼각형의 교차로 실제 횡단 요소 수/coverage를 측정한다. 표본 기반 검사이며 전 경계 보증으로 표현하지 않는다.
- mesh-study는 실제 서로 다른 3개 메시의 기하 면적·요소·벽 해상도 변화를 계산한다. neff/PML 손실 수렴을 대신하지 않는다.

## 검증 설계

25개 설계 JSON의 두 validator 및 저장/불러오기, 악성/잘못된 타입·기하 입력, 원/annulus 독립 해석 면적, PML·물리영역 라벨, 실제 법선 횡단 수, refinement 기하 수렴, 기존 전체 테스트를 실행한다.
아직 수행하지 않은 항목은 PASS로 기록하지 않는다. 별도 검증표·한계 보고서를 작성한 뒤 다음 단계 승인을 요청한다.

공식 API 근거: https://gmsh.info/doc/texinfo/gmsh.html#Specifying-mesh-element-sizes
Gmsh MeshSizeFromCurvature의 값은 2π당 목표 요소 수다. 최소 요소 수·오차 허용치는 물리 상수가 아니라 공개된 수치해석 검사 정책이다.
