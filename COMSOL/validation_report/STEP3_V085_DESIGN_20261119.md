# STEP 3 v0.8.5 — 설계 및 수용기준

승인: 사용자가 STEP 1·2의 도구 적용/업데이트 이력과 STEP 3 작업을 요청했다. 기존 HCurl/H1 혼합 정식화와 스칼라·Yee·Colab 자산을 유지한다. 다음 섬유별 단계는 이번 범위가 아니다.

## 구현 설계

- 기존 K0+βK1+β²K2 조립을 재사용한다. Nédélec1/P1 기본과 선택적 Nédélec2/P2를 제공한다.
- 기존 companion shift-invert를 보존하고, 동일 블록 구조에서 동치인 β² 일반화 고유계 옵션을 추가해 두 배 companion 크기를 줄인다. 복소 ε/μ PML의 비에르미트 행렬을 일반 sparse shift-invert로 푼다.
- 고유값만으로 퇴화 모드를 삭제하지 않는다. 물리영역 장의 선형 독립성·Gram rank로 중복을 판정한다.
- Gauss 약형은 외곽 Dirichlet test DOF를 제외한다. PML의 H 복원에는 변환된 μ^-1을 적용한다. 6성분·QEP/선형화 잔차·유한성·전력·PML 분율을 출력한다.
- 고정 물리영역의 동일 probe 점에 FE 장을 평가해 재메시/창/PML 간 모드 및 퇴화 부분공간을 추적한다.
- loss sign을 보존하고, 검증 report의 입력 hash가 일치하는 경우에만 검증 상태를 표시한다. 개별 solve가 스스로 loss 인증을 선언하지 않는다.
- SBC는 fixed-target Robin 근사라는 한계를 명시하고 β 의존 보정 가능성을 검토한다. 근사 SBC를 COMSOL 원통형 2차 경계와 동일시하지 않는다.

## 이번 V번호의 명시적 정의

원래 요청에 번호별 세부 명세가 없으므로 다음은 이번 단계의 공개 수용기준이다. 외부 인증 규격이나 COMSOL의 지정 허용오차가 아니다.

| ID | 시험 | 수용 정책 |
| --- | --- | --- |
| V1 | 원형 step-index의 정확한 벡터 HE11 특성 방정식과 비교 | 최소 3개 실제 메시, Re(neff) 절대오차 및 마지막 메시 차이 각각 1e-5 이하; 편광 쌍·계산창 영향 함께 보고 |
| V4 | 선형대수/물리 모드 무결성 | QEP 및 해당 pencil 잔차 1e-7 이하, 모든 장 유한, guided benchmark에서 Gauss 진단·PML 분율·양의 전력, 퇴화 쌍의 선형 독립성 확인 |
| V5 | 개방 경계/PML 검증 | 3개 두께·강도·차수와 물리창/메시 변화, 동일 장 또는 부분공간 추적; 충분히 큰 양의 Im(neff)는 상대 spread≤5%, 0 근처는 절대 noise floor를 보고하고 극소 손실 인증을 보류 |

진짜 방사 누설의 독립 기준을 통과하지 않은 경우 V5를 부분 통과(흡수/무손실 한계) 또는 미통과로 명시한다. 모든 HCF의 dB/km 정확도를 선언하지 않는다. 허용오차는 결과에 맞춰 임의로 완화하지 않는다.
