- Python 116개 로컬 통과. 별도의 실제 FEM 파장 sweep과 vector PWE/독립 real-space TE/TM 비교가 공개 기준에서 PASS_SCOPED다. 실제 HCF loss, FM/HOM, surface anticrossing, complete bandgap, PCF 제품 성능은 미인증이다.
- 예시 finite FEM은 실제 계산한 4개 후보지만 core disk power가 약 1.76–7.70%로 낮다. 코어 구속/광섬유 설계 성공으로 과장하지 않는다. geometry proposal과 solver 연결을 검증한 것이며 물리 설계의 추가 개선·문헌 비교가 필요하다.
- 기본 고해상도 handoff가 DOF budget을 넘으면 명시적으로 실패한다. 원래 25개 preset 수치를 자동 축소하지 않는다. 공개한 작은 예시는 물리 파라미터/메시 조건을 별도로 명시한 계산 사례다.
- STEP4/5 기능을 기존 workbench의 단위셀/밴드/결함 탭과 공통 연구 JSON 편집기·모드/물리량 viewer에 추가했다. 입력 변경 시 결과를 무효화한다. 브라우저는 Python 결과를 시각화한다.
