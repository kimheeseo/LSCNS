# STEP6 v0.8.8 설계 및 수용 기준

사용자의 6a–6f 일괄 진행 요청에 따라 기존 FEM/열탄성 모듈을 확장한다. 각 단계의 결과·검증·한계는 개별 항목으로 기록한다. 기존 v0.7.1 웹 scalar, Colab/Yee, STEP1–5 및 6a/b 초기 자산을 재작성하지 않는다.

- 6a: 동일 메시와 공통 실제 FE probe. 퇴화 편광을 임의 단일 고유벡터로 연결하지 않고 2차원 부분공간 principal angle을 검사한다. 반경·방향별 signed 총손실, 직선 차이 및 turn loss를 저장한다.
- 6b: 출처 없는 PM 상수 기본값 없음. 기존 mechanical→epsilon coupling을 보존하고 동일한 공간 분포의 직교 편광 후보인지 확인한다. 실제 재료·COMSOL benchmark와 합성 pipeline 검증을 분리한다.
- 6c: N코어 FE supermode 및 실제 E/H core power. 유일한 동일 편광 even/odd 후보가 있고 원점 대칭 동일 2코어인 경우에만 κ. 수치 splitting/near-degeneracy, 불완전 spectrum은 공개한다.
- 6d: actual FE interpolation regular grids와 명시적 analytic Gaussian만 입력. 같은 파장, full-aperture norm. offset로 잘린 receiver를 재정규화하지 않는다. gap/tilt/Fresnel은 가정·단위·sampling 한계를 저장한다.
- 6e: 각 grid 점에서 실제 지정 evaluator를 호출, 비유한/실패 점 제외. 목적의 min/max·단위·feasibility 명시, Pareto와 목적별 실제 최적 입력 저장. 전역 최적 보증 없음.
- 6f: 통계 시연용 PMD 유지. signed 편광 branch 추적을 제공한 uniform DGD 계산과 longitudinal PMD 확장 제안을 구별한다.

수용 확인: independent Gaussian 크기·offset·각도·갭/Fresnel 공식 일치, signed 선형 Δn의 group index 상수 항등식, unitary 회전 subspace 불변, 잘못된 PM spatial pair/입력 거절, grid 실패·제약·재개·Pareto 정확성. 실제 PML bend 4조건 추적, 합성 PM pair, 2/3코어 실 FEM, trench 4점 실 grid, FEM SMF↔HCF 후보 overlap, ΔT=0 무응력. 124 Python 회귀시험·8 Node 시험과 실제 워크벤치 browser/모바일 검증. 수치 기준과 물리 인증의 차이는 검증표에 명시한다.

PCF V2 exact parameters.txt 미확인 및 V6 actual cutoff 미검증은 STEP6 구현 성공으로 덮지 않는다. 다음 외부 물리 검증은 해당 자료와 별도 승인을 받은 뒤 진행한다.
