# STEP7 v0.8.9 설계·판정 정책

사용자가 지정한 V1–V9 정의를 그대로 적용한다. V4/V5는 기존 STEP3 내부 번호와 의미가 달라 새 suite에서 정의를 분리한다. 기존 코드는 보존하고 세부 검증 모듈, 보고서, 브라우저 표시를 추가한다.

- 상태는 PASS/FAIL/NEEDS_EVIDENCE. 전부 PASS인 경우만 항목 완료 및 전체 완료를 허용한다. 결측, 불명확한 물리 모드, 허수 부호 미확인, 원 입력 누락을 0 오차로 대체하지 않는다.
- 공학적 허용 정책과 문헌의 불확도를 구분한다. V1 10ppm, PML/mesh 5% 등은 명시적 시험 수용 정책이다. 확인되지 않은 외부 benchmark tolerance는 null로 둔다.
- b–V는 독립 cylindrical Maxwell 해석근과 실제 mixed FEM을 비교한다. PML/mesh는 same-subspace overlap으로 연결된 fresh 계산을 사용하고 mesh edge/요소 수를 같은 입력 hash로 확인한다.
- V6는 actual periodic vector Maxwell FSM β root와 full-section FM 후보를 사용한다. 순수 silica index를 FSM으로 대체하지 않는다. 두 λ 및 finite plane-wave cutoff로 ESM 전체를 증명하지 않는다.
- V7은 actual ARF 모드 스펙트럼을 사용한다. capillary 값은 shift seed일 뿐 기준답이 아니다. core localization/overlap/peak/mesh/PML 근거 없이 ARROW 식 자체의 일치만으로 통과시키지 않는다.
- CSV는 quoted numeric literals/units/convention만 파싱하며 eval을 사용하지 않는다. COMSOL mode ID 또는 사용자가 확인한 row mapping이 필요하다. close-neff 자동 재배열 없음. 실제 vector result와 연결하되 수치 표 비교가 V2/V3 물리 판정을 바꾸지 않는다.
- 웹은 별도 benchmark library를 표시하며 현재 편집 중인 설계의 인증으로 오인하지 않도록 범위를 상시 표시한다. comparison 입력 변경은 이전 표를 무효화한다. 버전·시각·소스 hash·원 근거를 JSON에 남긴다.

검증: 실제 V1/PML/mesh/FSM/ARF, 독립 SI/dispersion/Gaussian identities, CSV 순허수·D지수·0분모·결측·잘못된 입력·행 대응 검사, 실제 UI/HCF/vector navigation·모바일·자동 업로드 비교·실제 vector 연동·global DOM ID 검사를 실행한다. software tests PASS와 physics suite 전체 PASS를 구별한다.

단계는 순서대로 진행한다. STEP7의 물리 미완료 결과를 먼저 보고·업로드했고, 사용자가 같은 요청에서 명시한 STEP8은 별도 소프트웨어 작업으로 이어간다. STEP8 진행은 물리 검증 gate의 통과나 STEP7 완료를 의미하지 않는다.
