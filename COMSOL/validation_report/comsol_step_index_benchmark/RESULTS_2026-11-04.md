# G.654.E concept validation vs COMSOL public benchmark — 2026-11-04

**Important distinction:** No publicly confirmed COMSOL numeric results for the **same measured G.654.E refractive-index profile (RIP)** were identified. The comparison below has *three distinct evidence levels*: (A) **direct matched-conditions COMSOL generic step-index mode**, (B) independent exact Bessel scalar/HE11 solutions, and (C) manufacturer's **different** G.654.E products. These must not be conflated.

## A. Direct COMSOL public Step-Index Fiber benchmark (NOT G.654.E)

Official source: https://doc.comsol.com/6.4/doc/com.comsol.help.models.rf.step_index_fiber/step_index_fiber.html

The published example specifies **core radius 8 µm, cladding radius 40 µm, n_core=1.4457, n_clad=1.4378, λ=1550 nm**, V≈4.895, and gives **fundamental neff=1.4444 (four decimals)**.

[Actual LSCNS solver run / GitHub Actions PASS](https://github.com/kimheeseo/LSCNS/actions/runs/41780881388) and [reproduction script](run.mjs).

The production radial FEM assumes **n_clad = silica Sellmeier**, unlike this official COMSOL example. We used a *test-only material adapter* to substitute COMSOL's constant cladding index at precisely two sites in the imported original JavaScript source; the FEM discretization, eigensolver, and field-integral algorithms were left unchanged. **The ordinary web preset was not modified.**

| Source | Fundamental neff |
|---|---:|
| COMSOL publicly reported (rounded to four decimal places) | 1.4444 |
| Independent scalar LP01 analytical Bessel solution | 1.444401844409 |
| LSCNS original scalar radial FEM + material adapter (750 elements) | 1.444401819379 |
| LSCNS original scalar radial FEM + material adapter (1800 elements) | 1.444401840064 |

- |FEM(750) − COMSOL *printed value*| = **1.8194e−6**, but COMSOL publication rounding is roughly ±5e−5, so this is **not a measured COMSOL solver error**.
- |FEM(750) − independent scalar Bessel oracle| = **2.5030e−8**.
- |FEM(1800) − scalar Bessel oracle| = **4.346e−9**.
- Full-vector COMSOL and scalar LP01 are distinct governing models, even if they closely agree in a given example.

## C. Actual manufacturer specifications are a different validation layer

- [LS PremierLink LE125 catalog](https://fliphtml5.com/plzsm/rgkq/20250925_%ED%86%B5%EC%8B%A0_%EB%B8%8C%EB%A1%9C%EC%85%94/): 1550-nm nominal MFD 12.5 µm; current model was *fitted* to this number — **not independent validation**.
- [Sumitomo PureAdvance-125](https://sumitomoelectric.com/products/optical-fibers/pureadvance): 1550-nm nominal MFD 12.5±0.5 µm, typical Aeff 125 µm². **Different commercial design**, not a fair error measurement.
- [Fujikura HSC-125 technical paper](https://www.fujikura.co.jp/eng/rd/gihou/backnumber/pages/__icsFiles/afieldfile/2022/03/02/51e_10.pdf): 1550-nm MFD 12.3 µm, Aeff 125 µm² and D 21 ps/(nm·km). These are **different product targets**, not COMSOL numerical values.
- [ITU-T G.654 (2024)](https://www.itu.int/epublications/publication/itu-t-g-654-2024-08-characteristics-of-a-cut-off-shifted-single-mode-optical-fibre-and-cable): the standard defines a specification range; it does **not** prescribe a unique neff/MFD/Aeff set for arbitrary G.654.E designs.

## Verdict and next steps

**PASS:** Scalar radial FEM reproduces the independent analytical scalar LP01 benchmark, and agrees with COMSOL's published *rounded* neff on its own matched-input generic step-index example.

**PRELIMINARY ONLY:** G.654.E-like *assumed* step-index model is internally consistent with the independent full-vector HE11 analytic result to a few e−6 for neff, but is not a true measured G.654.E RIP or independent COMSOL comparison.

**NOT YET VALIDATED:** G.654.E manufactured product neff, measured/IEC MFD, Aeff, D and slope, cut-off, bend loss, attenuation, PMD; product-specific COMSOL results.

To establish a true **G.654.E COMSOL vs LSCNS** error table, acquire the exact manufacturer measured RIP (n(r,λ), dopant dispersion), identical mode definition and wavelength, same outer domain/boundary, mesh convergence results, and exported COMSOL neff+complex Ex/Ey/Ez fields. Compare MFD definitions before using percentage errors. Avoid MFD-fitted Δn as independent evidence.
