# M8 검증 개선 진행 기록

## 중간 저장: 2026-10-20 (한국시간)

- 기존 HCF는 이상적 Dirichlet 모세관 해석식이며, 실물 ARF/NANF 검증이 아님을 확인.
- 모세관의 독립 방사형 P1 FEM 추가. 40→640 요소에서 횡방향 고유값·유효굴절률·분산 수렴 확인.
- 2코어 MCF의 무한 클래딩 원통함수 경계 정합 기준 코드 추가.
- 기본 조건: 파장 1.55 µm, 반경 4.1 µm, Δn=0.005, 중심 간격 16 µm.
- 원통함수 차수 6에서 결합 길이 약 10.63981638 mm.
- 코어 경계를 따르는 곡선 P2 FEM, 수렴 시험 및 최종 보고서 작성 진행 중.
- 여기의 수치 오차는 동일한 스칼라 모델 내부의 비교이며 제품·실측 오차가 아님.
