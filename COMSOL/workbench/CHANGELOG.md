# 변경 기록

## v0.1.0 — 2026-10-20

- 모델 탐색기·기하·재료·물리·메시·연구·결과를 연결하는 3열 연구용 UI.
- 로컬 Python HTTP 서버 및 별도 계산 프로세스. 단일 코어/HCF/2코어 MCF의 기존 FEM을 실제 실행.
- 단면·실제 메시·모드 분포·장/전력 전달·수치 기준·오차 표시.
- 메시 수렴·계산 영역 수렴·파장별 재해석.
- 입력 변경 시 이전 그래프를 숨기고 재계산 필요 표시. 결과 내보내기 비활성화.
- 모델 JSON 저장/열기, 결과 JSON/CSV/PNG 저장, 작업 로그.
- G.654.E/G.657.A1 등가 예시 및 SCUBA 125 예비 등가 모델. 실제 제조사 구조와 구분.
- GitHub Pages 정적 미리보기와 실제 로컬 Python 계산을 구분.
- Python 수치/HTTP 통합 테스트 및 GitHub Chromium 브라우저 QA 추가.
