# LS Wave Optics Workbench 설치·사용·결과 해석 가이드

이 도구는 **회사 PC의 Python에서 광섬유 FEM 계산을 실행하고 브라우저로 조작하는 앱**입니다. 원형 단일 코어, 동일한 직선 2코어 MCF, 이상적 중공 모세관의 설계 경향과 수치 수렴을 확인할 수 있습니다. COMSOL 설치나 라이선스는 필요하지 않습니다. COMSOL과의 직접 비교 검증은 아직 수행하지 않았습니다.

## 1. 무엇을 알 수 있나

| 하고 싶은 일 | 바꾸는 입력 | 확인할 결과 | 판단할 수 있는 범위 |
|---|---|---|---|
| 빛이 코어 주변에 얼마나 퍼지는지 비교 | 코어 반경, Δn, 파장 | 모드 분포, Aeff, MFD | 원형 스텝형 스칼라 기본 모드의 공간 분포 |
| 설계 변경에 따른 전파 특성 비교 | 반경, Δn, 파장 | neff, D | 가정한 재료·단면에서의 전파상수와 색분산 |
| 파장에 따라 모드가 어떻게 변하는지 확인 | 스윕 시작·끝·지점 수 | 파장별 결과 표와 그래프 | 각 파장에서 실제 재계산한 경향 |
| 두 코어 사이 결합 비교 | 코어 중심 간격, 반경, Δn, 파장 | 짝/홀 모드, Δneff, κ, Lc | 동일한 직선 무손실 2코어의 결합 |
| 중공 크기에 따른 이상적 모드 비교 | 중공 반경, 기체 굴절률, 파장 | neff, Aeff, D, kt² | 일정 기체 굴절률의 J0/Dirichlet 모세관 |
| 메시 때문에 결과가 변하는지 확인 | 요소 수 또는 목표 h | 메시 수렴 표, 독립 기준 오차 | 공간 이산화 오차와 잔여 변화 |
| 외곽 계산 경계가 너무 가까운지 확인 | 단일 코어 R, MCF 반폭 L | 영역 수렴 표 | 계산영역 절단 영향과 재메시 영향 |

G.654.E·G.657.A1·SCUBA 125 프리셋은 **등가 단면의 출발점**입니다. 프리셋 선택만으로 실제 제품 구조나 규격 적합성이 검증되지는 않습니다. 실제 섬유의 굴절률 분포와 측정 자료가 없으면 제품 오차율을 확정할 수 없습니다.

현재 UI에는 감쇠(dB/km), 굽힘 손실, PMD, 실제 케이블 누화, ARF/NANF 구속 손실, 벡터 전기장·편광, 임의 CAD의 해석 기능이 없습니다. Aeff만으로 비선형 계수나 허용 전송출력을 자동 결정하지도 않습니다.

## 2. 설치와 실행

### Windows: 처음 설치

1. Python **3.12 64비트**와 Python Launcher(`py`)를 준비합니다. PowerShell에서 `py -3.12 --version`을 실행해 확인합니다. 검증 환경은 Python 3.12입니다.
2. 위 **설치 ZIP**을 다운로드합니다. ZIP 안에서 직접 실행하지 말고, 예를 들어 `C:\LS_WaveOptics_Workbench_v0.1`로 압축을 풉니다. 아래 폴더 구조를 유지합니다.

   ```text
   LS_WaveOptics_Workbench_v0.1/
     COMSOL/
       workbench/START_WINDOWS.bat
       workbench/launch.py
       workbench/requirements.txt
       waveoptics_m7/src/
       waveoptics_m8/src/
   ```

3. `COMSOL\workbench\START_WINDOWS.bat`를 두 번 클릭합니다. 첫 실행은 가상환경과 패키지를 설치하므로 인터넷 연결이 필요합니다. 설치 중 실행 창을 닫지 않습니다.
4. 브라우저에서 `http://127.0.0.1:8765/`가 열리고 오른쪽 위에 **Python 엔진 연결됨**이 표시되는지 확인합니다. 자동으로 열리지 않으면 이 주소를 직접 입력합니다.
5. 기본 예제를 선택해 **모드 해석**을 누릅니다. 완료 로그와 새 결과가 나타나면 계산 준비가 끝난 것입니다.

필요한 M7/M8 해석기가 ZIP에 포함되어 있습니다. `workbench` 폴더만 따로 옮기면 계산 코드 경로가 없어집니다. Windows에서는 전체 저장소 복제보다 전용 ZIP을 사용하십시오. 저장소의 다른 경로에 Windows에서 사용할 수 없는 문자가 있습니다.

### Windows: 수동 설치

PowerShell에서 **압축을 푼 최상위 폴더**로 이동한 뒤 실행합니다. 다음 예시의 폴더 경로는 실제 위치로 바꿉니다. 가상환경 활성화 명령이 필요 없으므로 PowerShell 실행 정책을 바꿀 필요가 없습니다.

```powershell
cd C:\LS_WaveOptics_Workbench_v0.1
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r COMSOL/workbench/requirements.txt
.\.venv\Scripts\python.exe COMSOL/workbench/launch.py
```

배치 파일은 `COMSOL\workbench\.venv`를 만들고, 위 수동 방식은 최상위 `.venv`를 만듭니다. 둘 중 한 방식을 계속 사용하면 됩니다. 최초 의존성 설치에는 NumPy, SciPy, Matplotlib, scikit-fem, Gmsh가 포함됩니다.

### 다시 실행·종료·다른 포트

- 배치 설치: 다음에도 같은 `START_WINDOWS.bat`를 실행합니다.
- 수동 설치: 최상위 폴더에서 마지막 `launch.py` 명령만 다시 실행합니다.
- 종료: 브라우저 탭을 닫고 Python 실행 창에서 **Ctrl+C**를 누릅니다. 실행 중인 계산이 있으면 종료까지 기다릴 수 있습니다.
- 포트 충돌: 수동 실행 명령 끝에 `--port 8766`을 붙이고 `http://127.0.0.1:8766/`로 접속합니다.
- 브라우저 자동 열기 생략: `--no-browser`를 붙입니다.

서버는 `127.0.0.1`에서만 동작합니다. 최초 패키지 설치 후 수치 계산은 PC에서 수행됩니다. 다른 PC에 서버로 공개하는 기능은 제공하지 않습니다. 외부 문서 링크를 열거나 패키지를 다시 설치하는 경우에는 인터넷이 필요합니다.

### macOS / Linux

압축을 푼 최상위 폴더에서 다음을 실행합니다. Python 3.12가 준비되어 있어야 합니다.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r COMSOL/workbench/requirements.txt
.venv/bin/python COMSOL/workbench/launch.py
```

Ubuntu에서 Gmsh의 공유 라이브러리가 없다는 오류가 나면 다음 의존성을 설치한 뒤 다시 실행합니다. Linux는 검증했으며 macOS의 설치·GUI 동작은 별도로 검증하지 않았습니다.

```bash
sudo apt-get install -y libglu1-mesa libxft2 libxrender1 libxinerama1 libxcursor1
```

## 3. 화면 사용 순서

1. **오른쪽 설정 → 모델 / 예제 선택**에서 모델을 고릅니다. 처음에는 `단일 코어 · 검증 기본값`을 사용합니다.
2. 오른쪽의 **전역 파라미터·기하 구조·재료·메시** 값을 확인합니다. 왼쪽 모델 탐색기는 해당 설정과 보기로 이동하는 탐색 기능입니다.
3. **단면**에서 코어 위치와 계산 경계를 확인합니다. 단면 미리보기는 해석 결과가 아닙니다.
4. **메시 생성**을 눌러 실제 해석 메시를 확인합니다. 메시 생성만으로 모드가 계산되지는 않습니다. 바로 **모드 해석**을 눌러도 해석 과정에서 메시를 만듭니다.
5. **모드 해석** 또는 **현재 모델 계산**을 누릅니다. 한 번에 한 작업만 실행하며 완료 여부는 아래 로그에서 확인합니다.
6. 중앙의 **모드 분포**, **장 / 전력 전달** 탭과 결과 카드를 읽습니다. **수치 기준 · 오차 · 입력 기록**을 펼쳐 독립 기준과 실제 입력을 확인합니다.
7. **메시 수렴**, 필요한 경우 **영역 수렴**을 실행해 결과의 안정성을 확인합니다. HCF는 영역 수렴 대신 메시 수렴을 사용합니다.
8. 오른쪽 **파장 스윕 · 미분**의 범위를 정하고 **파장 스윕**을 실행하면 조건별 표와 연구 그래프를 얻습니다.
9. **모델 저장**, **JSON**, **CSV**, **PNG**로 연구 조건과 결과를 남깁니다.

입력을 바꾸면 **입력 변경 · 재계산 필요**로 표시되고 이전 그래프·내보내기를 현재 결과로 사용할 수 없게 됩니다. 다시 해석한 뒤 저장하십시오. 확대/축소/맞춤은 화면 표시만 바꾸며 메시를 세분화하지 않습니다.

수렴·스윕 연구 후 결과 카드는 **마지막 계산 조건**의 값입니다. 예를 들어 영역 수렴 후 카드의 값은 처음 입력한 R이 아니라 R+4 µm 조건입니다. 전체 조건은 연구 표와 결과 JSON의 `rows`, 마지막 조건은 `last_condition`에서 확인합니다. 기본 조건을 다시 확인하려면 **모드 해석**을 누릅니다.

## 4. 입력값과 단위

아래 범위는 **앱의 입력 제한**입니다. 그 범위의 모든 조합에 물리적 타당성이나 제품 정확도를 보장하는 의미는 아닙니다. 모델별로 필요한 항목만 화면에 표시됩니다.

| 입력 항목 / JSON 키 | 단위 | 기본 예시 | UI 범위·의미 |
|---|---|---|---|
| 해석 파장 / `wavelength_nm` | nm | 1550 | 800–2200; 스윕의 모든 파장에서도 모델 조건을 만족해야 함 |
| 코어 반경 / `radius_um` | µm | 4.1 | 1–10; 지름이 아니라 반경 |
| 굴절률 차이 / `delta_n` | 무차원 | 0.005 | 0.0001–0.02; 절대 차이 n_core−n_clad, 백분율 아님 |
| 단일 코어 계산 반경 / `outer_um` | µm | 40 | 15–60; 실제 섬유 클래딩 반경이 아닌 수치 경계 |
| MCF 계산영역 반폭 / `outer_um` | µm | 32 | 15–45; 전체 정사각형의 한 변은 2L |
| 코어 중심 간격 / `pitch_um` | µm | 16 | 3–30; 코어 가장자리 사이 거리가 아님 |
| 코어·클래딩 요소 / `core_elements`, `clad_elements` | 개 | 160, 640 | 40–640, 80–2560; 방사형 P1 요소 수 |
| MCF 목표 요소 크기 / `mesh_size_um` | µm | 0.7 | 0.3–1.5; 작을수록 일반적으로 요소 수 증가, 실제 수는 결과에 표시 |
| 중공 반경 / `hcf_radius_um` | µm | 15 | 3–100; HCF 모세관의 물리적 외벽 위치 |
| 기체 굴절률 / `n_air` | 무차원 | 1.00027 | 1–1.1; 파장·온도·압력에 대한 변화는 모델링하지 않음 |
| 중공 방사형 요소 / `hcf_elements` | 개 | 320 | 40–1280 |
| 분산 미분 간격 / `derivative_step_nm` | nm | 5 | 0.5–10; 단일 코어 D의 동일 메시 5점 미분 간격 |
| 스윕 시작·끝 / `sweep_start_nm`, `sweep_end_nm` | nm | 1530, 1625 | 각각 800–2200, 시작 < 끝 |
| 스윕 지점 / `sweep_points` | 개 | 7 | 정수 3–11 |

단일 코어와 MCF의 실리카 클래딩 굴절률은 Sellmeier 식으로 계산하고, 코어는 그 값에 일정 Δn을 더합니다. 순수 실리카 코어·불소 도핑 클래딩 등 실제 제품의 재료 조성을 그대로 표현하는 모델은 아닙니다.

단일 코어와 MCF는 고립 코어의 V<2.405 범위만 허용합니다. MCF는 중심 간격 > 코어 지름, L > p/2+2a, h≤a, L/h≤150 조건도 만족해야 합니다. 입력 범위를 넘으면 로그에 오류가 나타나며, 더 큰 임의 모델을 자동으로 계산하지 않습니다.

## 5. 결과값 읽는 법

| 결과 | 의미와 연구에서의 용도 | 주의할 점 |
|---|---|---|
| 유효굴절률 neff | β=k₀·neff로 전파상수를 나타냄. 설계·파장별 위상 특성 비교 | 기체/재료 굴절률과 다른 모드의 값. neff 자체는 군굴절률이 아님 |
| Aeff, µm² | 장의 집중도를 나타내는 유효면적. 같은 모델에서 공간적 퍼짐 비교 | 스칼라 장 적분값. 실제 제품 비선형 성능을 단독 결정하지 않음 |
| 2차 모멘트 MFD, µm | 강도 분포의 2차 모멘트로 정의한 모드 크기 | Petermann-II MFD와 정의가 다르므로 비교 대상을 일치시켜야 함 |
| Petermann-II MFD, µm | 단일 코어 FEM 장의 기울기 적분으로 산출한 모드 크기 | 제품 MFD와 비교할 때 파장·정의를 맞춤. UI에 독립 오차율은 없음 |
| D, ps/(nm·km) | 색분산. 단일 코어는 재료와 도파관 기여가 포함된 neff의 파장 미분 | 손실이나 PMD가 아님. 단일 코어는 메시와 미분 간격 모두 확인 |
| 짝/홀 neff | 동일 2코어의 두 슈퍼모드 전파 특성 | 편광 모드가 아님 |
| Δneff | 짝모드 neff−홀모드 neff; 결합 강도를 판단하는 작은 차이 | 두 neff가 각각 정확해 보여도 차이의 상대 오차는 클 수 있음 |
| κ, 1/m | κ=π·Δneff/λ; 이상적 동일 코어의 결합 계수 | 식에서 λ는 m 단위 |
| Lc, mm | Lc=λ/(2Δneff); 처음 완전 전력 전달이 일어나는 길이 | 전력 왕복 주기는 2Lc. 실제 케이블 누화 길이와 같지 않음 |
| kt², 1/µm² | HCF 모세관의 횡방향 고유값 | 실제 반공진 공진점이나 손실을 뜻하지 않음 |
| 모드 분포·장 그래프 | 계산한 스칼라 장 ψ 및 정규화된 상대 강도 | 절대 W, W/m² 또는 Ex/Ey/Ez 출력이 아님 |

단일 코어·HCF의 2D 장 그림은 **실제 방사형 FEM 해를 회전 대칭으로 재구성**한 것입니다. MCF는 실제 곡선 P2 FEM의 1/4 영역 해를 대칭으로 복원합니다.

단일 코어 스윕은 neff·Aeff·두 MFD를 계산합니다. D는 원하는 파장에서 별도의 **모드 해석**으로 구합니다. HCF 스윕에는 일정 기체 굴절률 가정의 D가 포함됩니다. MCF 스윕은 짝/홀 neff·Δneff·Lc·κ를 계산합니다.

## 7. 메시·계산영역·분산 검증

**메시 수에 따라 값이 달라집니다.** 연속 방정식을 유한한 요소로 근사하기 때문입니다. 메시를 늘려 잔여 변화를 확인하고 외곽 경계·미분 간격의 영향을 별도로 확인해야 합니다.

1. **메시 수렴:** 물리 입력과 계산영역을 고정합니다. 단일 코어 기본값은 40/160 → 80/320 → 160/640, HCF는 80 → 160 → 320 요소를 비교합니다. MCF 기본 h=0.7은 h=1.26 → 0.945 → 0.7 µm를 비교합니다. 더 작은 h가 더 촘촘한 설정입니다.
2. **영역 수렴:** 단일 코어는 기본 R=40, 42, 44 µm, MCF 프리셋은 L=32, 34, 36 µm를 비교합니다. 각 조건은 재메시하므로 순수한 경계 오차와 잔여 메시 오차가 함께 포함됩니다. 방사형 모델은 클래딩 요소 수가 같으면 R 증가 시 요소 간격도 커집니다. 필요하면 영역을 키운 뒤 요소 수도 늘려 재확인합니다.
3. **분산 미분:** 단일 코어에서 메시를 충분히 세분화한 뒤 미분 간격 5 → 2.5 → 1 nm 등으로 **모드 해석**을 반복합니다. 간격을 무조건 줄이면 차분의 상쇄·고유값 오차 때문에 D가 오히려 불안정할 수 있습니다.
4. **목표량으로 판단:** neff만 보지 말고 보고할 Aeff, MFD, D 또는 MCF의 Δneff·Lc가 안정적인지 확인합니다. 마지막 두 조건의 상대 변화와 독립 기준 오차를 함께 기록합니다.

예를 들어 연구에서 Aeff 상대 변화 0.1% 미만을 채택하려면 그 기준과 사용 조건을 명시하고 달성 여부를 표로 확인합니다. **0.1%는 사용자가 정하는 수렴 허용치의 예시이며, 제품 정확도 보증이나 앱 전체의 통과 기준이 아닙니다.**

표시 오차는 neff에 대해 `abs(FEM−reference)`인 **절대 오차**, 다른 기준이 있는 항목은 `100×abs(FEM−reference)/abs(reference)`인 **상대 오차(%)**입니다. neff 오차 10⁻⁸을 10⁻⁸%로 읽으면 안 됩니다. 오차 칸이 없는 결과는 오차가 0이라는 뜻이 아닙니다.

오차 원인은 메시 이산화, 유한 외곽 경계, 재료 프로파일 단순화, 파장 미분, 실제 구조와의 모델 차이로 구분해야 합니다. 선형 고유문제의 작은 residual만으로 메시 수렴이나 실제 제품 정확도를 증명할 수 없습니다.

## 10. 해석 범위와 검증 근거

v0.1은 Linux·Windows에서 각각 Python 수치/HTTP 테스트 15개와 Chromium 통합 동작 10개를 통과했습니다. [최종 검증 보고서](FINAL_VERIFICATION.md)에 실행 링크, 기계 판독 기록, 실제 화면이 있습니다. Windows는 배포 ZIP을 직접 풀어 엔진/HTTP를 검사했으며, 배치 파일 두 번 클릭부터 브라우저를 여는 수동 GUI 전체 과정은 별도 확인이 필요합니다.

독립 기준은 단일 코어의 원형 Bessel 해, MCF의 무한 클래딩 원통함수 경계 정합, HCF의 J0 모세관 해입니다. 모두 해당 이상화 스칼라 모델에 대한 검증입니다.

- [단일 코어 및 M7/M8 연구용 검증](../research/README.md)
- [2코어 MCF 검증 보고서](../waveoptics_m8/MCF_2CORE_VALIDATION_REPORT.md)
- [이상적 HCF 검증 보고서](../waveoptics_m8/HCF_VALIDATION_REPORT.md)
- [입력·출력 Colab 보고서](../fiber_simulation_guide/readme.md): 별도 노트북의 실행·검증 조건을 확인하십시오. 현재 브라우저 앱과 동일한 모든 조건을 사용하는 것은 아닙니다.

**UI가 COMSOL과 비슷해도 풀고 있는 물리 모델은 제한적입니다.** 실제 COMSOL 벡터 Wave Optics 결과와 비교하려면 같은 형상·재료·경계·모드·수렴 조건을 맞춘 별도의 비교가 필요합니다. 현재 도구는 위 세 모델의 설계 경향과 수치 검증에 사용할 수 있으며, 범용 COMSOL 대체 도구나 실제 제품 인증 도구로 검증된 상태는 아닙니다.

이 가이드와 예제 모델은 검증된 v0.1 코드의 문서 보완입니다. 기존 설치 ZIP과 `SOURCE_MANIFEST.json`은 검증 당시 배포본의 기록으로 유지하며, 이 최신 가이드는 GitHub에서 별도로 제공합니다.
