계산 가정과 참고 그림

제공된 3개 공정도의 수직 배치와 두 단계 코팅·UV 경화를 참고했습니다. 원본 이미지는 이 파일에 포함하지 않았으며 외부 이미지·모델·폰트를 사용하지 않습니다.

기본 코어 직경 8.2 µm는 예시 구조값이며 MFD가 아닙니다. 코어/클래딩 비율은 인출 시 일정하다고 가정합니다. 1차 코팅 방사 두께 32.5 µm, 2차 27.5 µm를 고정하여 정상 조건에서 190/245 µm가 됩니다. 실제 코팅 직경은 금형·수지·압력·속도에 따라 달라집니다.

장력은 T = 0.12 + 0.008 Vf + 0.0004 |Df − 125| [N]의 교육용 정상상태 모델입니다. 냉각 온도는 로 출구 약 1,400 ℃에서 코팅 전 45 ℃로 내려가는 개념 분포입니다. 열유동·점도·장력·UV 경화의 연성 해석이나 실제 센서 측정값이 아닙니다. 온도 조절은 색상에만 반영됩니다.

입력 변경은 정상상태를 즉시 재계산합니다. 기동은 28초의 교육용 순서 시연이며 실제 장비 가동 시간과 다릅니다. 작업자·호이스트·초기 실걸기·보빈 연결 동작은 공정 이해를 위한 단순화이며 실제 작업 표준을 나타내지 않습니다. 전달 지연·파단·proof test는 포함하지 않습니다. 입자와 휠 회전은 이동 방향을 보여주도록 감속 표시합니다. 보빈 권취층의 성장은 식별을 위해 과장하며 실제 권취량/만권 용량 계산은 아닙니다. 생산 길이와 유리봉 소모는 가상 시간에 맞춰 누적하며 탭을 숨기면 자동으로 멈춥니다.

Three.js r128만 cdnjs.cloudflare.com에서 불러옵니다. 최초 실행에는 인터넷이 필요합니다. WebGL 미지원 시 동일 장면을 CPU 호환 보기(최대 10회/초, 단순 표면)로 표시합니다. 60 fps는 WebGL 모드의 목표이며 기기에 따라 다릅니다.
