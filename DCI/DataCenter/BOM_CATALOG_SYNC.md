# BOM 제품 카탈로그 동기화

2026-10-05 · v8.1.3

`bom-catalog.js`는 GitHub main 커밋을 고정한 뒤 `product_catalog` Git 트리의 모든 `catalog.json`을 조회합니다. 업체와 경로를 코드 목록으로 제한하지 않습니다. 동시에 최대 6개 파일을 조회하고 동일 커밋의 결과를 5분간 재사용합니다. BOM의 **제품 목록 동기화** 또는 업체 목록의 **카탈로그 새로고침**은 새 커밋을 다시 조회합니다. 일부 파일 오류는 화면에 표시하고 이전 제품을 신규 결과로 재사용하지 않습니다.

`bom-catalog-ui.js`는 기존 장비 설계와 용량 설계가 공유하는 **설계 제품·케이블 품목 리스트**입니다. 현재 선택된 대안의 BOM, 설계 참고 수량과 등록 제품을 연결하며 업체별 필터를 제공합니다. Phase별 동일 규격을 합산하되 대안과 규격·길이를 구분합니다. 제품 후보는 수량을 변경하지 않습니다.

영문/한글 사양 키를 정규화합니다. 알려진 속도·거리·커넥터·광 규격·프로토콜 충돌은 제외합니다. 필요한 사양이 미등록이거나 제품군이면 **관련 제품 · 검증 필요**로 표시합니다. 충분한 공개 사양이 일치해도 **규격 후보 · 장비 호환 검증 필요**이며 구매 승인/인증을 의미하지 않습니다. Ethernet 후보를 InfiniBand 확정 제품으로 표시하지 않습니다. AEC/DAC/AOC를 구분하고 광모듈을 케이블 후보에 중복 연결하지 않습니다. UPS/발전기/변압기의 개별 수량은 용량 설계에서 미산정 참고 항목으로 남깁니다.

CSV·Excel에는 품목별 후보, 확인 상태, 근거, 공식 URL, 카탈로그 경로와 Git SHA를 함께 내보냅니다. 기존 장비 Excel과 용량 설계 Excel은 동일한 제품 후보 테이블을 사용합니다. 기존 엔진의 설치·예비품·구매 수량과 비용 산정 로직은 변경하지 않습니다.

검증: `node --test DCI/DataCenter/tests/bom-catalog.test.cjs`

- Coherent 한글 사양 정규화와 속도/광 규격/거리 충돌 제외
- Amphenol AEC 길이 및 PCIe/Ethernet 분리, 매칭 시 입력 수량 불변
- Eaton UPS/Schneider 랙 분류와 미산정 참고 상태
- 새 경로 발견, 커밋 변경 재조회, 조회 실패와 재시도
