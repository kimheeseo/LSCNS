# LS cable and optical connection power — 2026-10-11

실행 화면의 **전력·냉각** 탭에서 **LS전선 관점 · 광섬유·케이블과 연결 전력**을 확인하세요.

수동 광섬유 1심과 광케이블 자체의 전기적 소비전력 기준은 0 W입니다. 광파워(mW/dBm), 광손실(dB), 장비 소비전력(W), 사용 에너지(kWh)는 서로 다른 물리량입니다. 채널 감쇠 개선 dB를 전력 절감 W로 직접 환산하지 않습니다. 능동 모듈·레이저·PHY·케이블 회로의 전력은 제품별 사양과 전력 경계로 확인해야 합니다.

## 현재 엔진에서 확인한 범위

- 공개 입력/출력에는 광섬유 1심·수동 케이블 1개당 W 계수가 없습니다.
- 서버·스위치 등을 포함한 장비 설계전력을 집계합니다. 제품별 광모듈·AOC/AEC W는 별도 제공되지 않습니다. 이를 해당 능동 부품의 0 W로 해석하지 않습니다.
- 2026-10-11 공개 계산 API로 조회한 B200/1024 GPU/rail/IB 예시: 서버 128대 × 14.3 kW = Compute 1,830.4 kW; 총 IT 1,912.96 kW. 차이는 장비 부하로 집계되지만, 광모듈별 W의 독립 분해 근거는 반환되지 않았습니다.
- 해당 예시의 Server–Leaf 400G AOC는 별도 플러거블 모듈 수가 0으로 반환됩니다. 이는 AOC 전력 0 W를 뜻하지 않습니다. Leaf–Spine에는 설치 물리 광모듈 1,024개와 구매 모듈 1,127개가 구분되어 있습니다.
- 서버/스위치 정격 전력이 광모듈까지 포함하는지, 스위치 전력에 광엔진·ELS가 포함되는지 확인하기 전에는 참고 계산 값을 기존 IT 전력에 더하지 않습니다.

## 참고 계산 사용법

1. 실제 설치 물리 광모듈 수(양단 합계)를 입력합니다. 현재 설계에서 설치 모듈 수만 가져올 수도 있습니다. 예비 재고는 소비전력 수량에서 제외합니다.
2. 같은 SKU의 최대 W 또는 측정 평균 W를 입력합니다. 가져오기 시 W는 미확인 상태로 초기화됩니다. 다른 SKU는 따로 계산해서 합산합니다.
3. AOC/AEC/ACC는 실제 설치 어셈블리 수와 양 끝·모든 분기를 포함한 전체 W를 입력합니다. AOC 내부 광회로에 플러거블 전력을 다시 더하지 않습니다.
4. 운영 시간(h)을 입력합니다. P(W) = Nmodule × Wmodule + Nassembly × Wassembly; E(kWh) = P ÷ 1,000 × h.

값이 비어 있는 능동 부품은 산정 대기로 표시합니다. 이 참고 계산은 장비 IT/PUE 계산 및 구매 BOM을 자동 변경하지 않습니다. 최대 소비전력으로 구한 kWh는 최대 부하 가정의 에너지 예산이며 실제 평균 사용량이 아닙니다.

공식 예제: NVIDIA MMS4X00-NS400의 400G 최대 소비전력은 모듈당 9 W, DR4 활성 광섬유는 8심입니다. 동일 모듈 2개는 18 W, 24시간 예산은 0.432 kWh. 이를 8심에 나누면 2.25 W/활성심이라는 연결 장비 전력 배분 지표가 되지만, 수동 광섬유의 소비전력이 아닙니다. 9 W는 전체 400G 제품이나 Twin-port 모듈에 적용하는 공통 계수가 아닙니다.

- https://networking-docs.nvidia.com/mms4x00ns400/specifications
- https://www.nvidia.com/en-au/networking/ethernet/direct-attach-copper-cables/

전력 케이블은 전달 용량(kW)과 자체 도체 손실(ΣI²R W)을 구분합니다. PoE 데이터 케이블도 도체 손실과 발열을 확인해야 합니다. 수동 케이블에 능동 회로가 없다는 설명을 도체 손실 0으로 일반화하지 않습니다.
