# 설계 툴 첫 진입 개선 · 2026-10-16

대상: `DCI/DataCenter/index.html` (BOM 설계 홈).

## 변경 및 사용법

- 기본 입력은 GPU 수·시스템·토폴로지 3개. 랙·냉각, Facility/Storage, 보조장비, 패브릭·배선, 가정값은 고급 옵션에서 펼친다.
- 1,024 GPU B200 Rail, 256 GPU H200 Dual, GB200 NVL72 4랙 프리셋. 선택 시 고급 가정도 초기값으로 복원하고 자동 계산한다.
- 첫 방문 시 모든 입력 모듈 장착 후 기본 예제를 자동 계산한다. 입력을 바꾸면 이전 결과를 재계산 중이라고 표시한다.
- 상단에 랙별 최대 전력·냉각 부하 및 사용+예약 RU를 한도와 비교한다. 한도 초과, 예비율 부족, 냉각 방식 계획 기준을 구분한다. NVL72는 OEM 전체 랙 RU 기준이며 일반 예약 RU를 중복 추가하지 않는다.
- 결과의 ‘산출 근거’에서 현재 값을 대입한 IT/시설 전력, PUE, 랙 수용량, 냉각 열부하·유량, oversubscription, UPS 용량 계산과 출처를 확인한다.
- 상세 검증·수량 요약과 3D JSON 가져오기는 접어서 표시한다. 3D 공유 해시로 진입하면 가져오기 안내는 유지한다.
- 별도 ‘용량’ 설계 모드에서는 기존 용량 모드 결과를 사용하며, 장비별 설계의 상단 한도 패널을 숨겨 서로 다른 결과를 혼동하지 않도록 한다.

## 확인

Chromium 브라우저에서 기본 자동 계산, 기본 필드 3개 노출, 세 프리셋, 고급 옵션 초기 닫힘, PUE/oversub 수정 및 재계산, 세 한도 초과, 프리셋 초기화, 탭 간 경고 유지, 중복 ID 및 JS 예외 없음 확인.
1440px / 390px 화면에서 문서 가로 넘침 없음 확인. 외부 제품 카탈로그는 로컬 검증에서 제공하지 않았으며 품목 추천·Excel 내보내기는 이번 검증 범위가 아니다.

재현 가능한 한도 검사: `node --test design-checks.test.cjs`.
기본 예제: 1,024 GPU, 128 시스템, Compute 32랙, 전체 37랙, IT 1,937.4 kW, PUE 1.2 → 시설 2,324.88 kW.
공랭 30 kW/랙 계획 기준에 비해 Compute 랙 57.2 kW이므로 경고가 표시되는 것이 정상이다.

모든 값은 계획 가정이다. PUE의 에너지 비율 정의를 정전력 시나리오에 적용하며, UPS 식은 기존 모델의 보수적 용량 근사이다. 제품 적합성 인증이나 UPS 배터리 잔여시간 계산을 뜻하지 않는다.
