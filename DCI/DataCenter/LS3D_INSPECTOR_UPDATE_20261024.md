# 검사 패널 및 도구 메뉴 개선 · 2026-10-24

1. MEP 작업·광 연결·FPS/기기 검증·랙/MEP 검사·공통 BOM/호환성·종합 점검 버튼을 왼쪽 07 NOC/Safety 아래로 이동했습니다. 모바일에서는 3D 화면 위의 접을 수 있는 검증·설계 도구 메뉴를 사용합니다.
2. 오른쪽 3D 설비 검사에 설비 선택과 부품·구조물 선택 목록을 추가했습니다. 설비를 바꾸면 해당 랙 내부 부품과 주변 구조물 목록이 갱신됩니다.
3. 3D에서 부품을 클릭하거나 목록에서 선택하면 검사 패널 상단에 이름·소속 설비/구역·U 위치·용도를 표시합니다. 부품 설명을 화면 위에 중복 표시하지 않습니다.
4. 전력/광케이블 트레이의 레일·행거·가로 지지대와 천장 구조 보에 선택 정보를 추가했습니다. 동일 트레이의 여러 구성요소는 목록에 한 항목으로 묶고, 클릭한 구성요소 종류를 별도로 표시합니다.

노란색 랙 상부 구조물은 현재 모델의 전력 케이블 트레이입니다. 케이블을 지지하는 구조물이며 별도 설비인 상부 Power Busway와 구별합니다. 색과 치수는 교육용 예시입니다.

기존 카메라·카세트 인출·BOM 계산 기능을 유지합니다. 검사 패널의 부품 선택 해제로 강조 표시를 해제할 수 있습니다.
