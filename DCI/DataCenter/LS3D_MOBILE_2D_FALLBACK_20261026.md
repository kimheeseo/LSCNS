# 모바일 UI · 저사양/WebGL 미지원 화면 개선 (2026-10-26)

## 구현

- **모바일 우선**: 폭 790px 이하 또는 강제 `display-mobile`에서 기본 3D 화면 우선 표시.
  - 우측 `3D 설비 검사` 본문은 기본 접힘, "설비 검사·상세 펼치기" 버튼으로 열기/닫기.
  - "시뮬레이션 단계" 레일도 기본 접힘. 기존 업무/운영 정보, 검증 도구 패널의 접힘 상태는 유지.
  - Phase 5–7 및 랙 상세 화면은 사용자가 열 때만 모바일 하단 시트(최대 높이 62–65dvh)로 표시.
  - 안내 모달은 모바일 첫 로딩에서 자동 전면 표시하지 않음; `? 안내`로 다시 열 수 있음.
- **성능**: 모바일 실렌더 호출 간격을 최소 약 33ms로 조절(호출 상한 약 30fps). 백그라운드 탭은 최소 1,000ms 간격. 모바일 첫 설정을 `품질: 낮음`으로 설정하며 사용자 버튼으로 다시 변경 가능. 기존 Three.js 적응형 DPR·LOD/Frustum 최적화 기능 유지.
- **WebGL 미지원 / 그래픽 컨텍스트 손실**: 별도 2D 평면 SVG 도면 자동 표시. 구역 이동, 랙·설비 선택, 기존 검사 정보 및 검색용 선택 목록과 연결. GPU·외부 3D 라이브러리 불필요.
- **사용자 선택**: 상단 `2D 경량` 버튼 또는 `?view=2d` 주소 파라미터로 강제 진입 가능. WebGL을 사용할 수 있으면 `3D 돌아가기`로 복귀 가능. WebGL이 없으면 복귀 버튼 숨김.
- **2D 화면**: 전체 캠퍼스에서는 구역 클릭 → 구역 배치도로 진입, 구역에서는 랙/설비 탭 또는 선택 목록으로 선택. 2D 평면도는 기존 `__LS3D_TEST__.visibleAssets()`, `visibleZones()`, `setZone()`, `pickAsset()`을 사용하여 3D 설계 데이터와 동일한 자산 ID·좌표·상태를 공유.
- **기존 2D Gold Pixel Tour** 링크는 추가 대안으로 유지.

## 변경 파일

1. `LS_Datacenter_3D.html`: 경량 모드 로딩, 렌더링 우회, 모바일/백그라운드 호출 간격 제한
2. `LS_Datacenter_3D_Mobile_Fallback.js`: 모바일 메뉴 접기, 선택 가능한 SVG 평면도, WebGL 미지원/컨텍스트 손실 처리, 모바일 품질 기본값

## 검증 근거

- GitHub에서 변경 스크립트 재조회 후 JavaScript 구문 검사 PASS.
- 메인 HTML 내 비외부 스크립트 및 importmap 문법 검사 PASS.
- 브라우저 DOM 모의 환경에서 `gl=false` 구동 시 자동 SVG 경량 모드, SVG 구조 생성, 자산/구역 선택, 저화질 설정, 3D 복귀 비활성화 검사 PASS.
- **미완료**: 실제 Android/iOS Chrome/Safari, 실기기 WebGL 컨텍스트 손실 및 실제 프레임레이트/FPS 계측, 배포된 GitHub Pages 상 화면 크기별 스크린샷 회귀 테스트.
- 2D 도면은 개념적 인프라 배치도이며 실측 CAD/BIM 또는 시공 승인 평면도가 아님.
