# 3D 랙 광패널 상세 개선 · 2026-10-23

## 사용 방법

`LS_Datacenter_3D.html?engine=three` → 랙 선택 → 문 열기 → **LS 광패널 상세**.
**모듈 분해 보기**로 카세트 하우징과 내부 광섬유를 확인할 수 있습니다.
포트를 클릭하거나 **광 커넥터 선택·확대**로 24개 LC duplex 포트를 순서대로 선택합니다.

`rack-detail-review.html`은 같은 부품 코드를 사용하는 SVG 투영 검토 화면입니다.
WebGL 없이 전체 랙·광패널 확대·카세트 인출/복귀·모듈 분해/조립을 확인합니다.

## 변경

- 광패널: 금속 외함, 4슬롯 모듈 가이드, 체결 이어, 고정 레일, 인출 손잡이.
- 카세트: 별도 바닥·측벽·전면 아답터 플레이트·개폐 덮개·릴리스 탭.
- 후면: 모듈당 MPO 12F 입력 1개, 커넥터 부트와 트렁크 고정부.
- 내부: 12색 팬아웃 광섬유와 여장 가이드. 사전 종단 카세트이므로 별도 융착부로 표현하지 않음.
- 전면: 모듈당 LC duplex 6개, 전체 24 duplex/48심인 교육용 예시. 일부 패치코드 표현.
- 랙: U 마운팅 홀, 서버 마운팅 이어·인출 손잡이·드라이브 베이.
- 부품 선택 시 연결 역할 및 설계 범위를 설명. 상세 광섬유는 인출 시 최초 생성하여 중복 생성 방지.

## 검증

- 수정 모듈 및 HTML 내 JavaScript 구문 검사 통과.
- 실제 Three.js 부품 모델을 SVGRenderer로 표시하고 확대/분해 형상 확인.
- 4모듈, 24개 고유 포트, 포트 선택 매핑, 지연 상세 생성, 48개 내부 광섬유,
  반복 갱신 중 메시 중복 없음, 분해, 완전 복귀: 동작 검사 8/8 통과.
- 메시 좌표 유한성 검사: 비정상 좌표 0개.
- 검증 브라우저가 WebGL2를 지원하지 않아 전체 투어의 WebGL 렌더링·FPS·모바일 터치는 미검증.
- 2D 투어와 BOM 계산 엔진은 수정하지 않음.
