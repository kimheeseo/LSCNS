## 실제 KPI 계산식 (시뮬레이션용)
- IT 부하 = [설정 랙 수 × 랙당 전력 + (광 포트당 W × 포트 수 / 1000) + 광 네트워크 스위치 전력] × 장애/부하 시나리오 계수.
- 냉각 전력 = IT 부하 / 유효 냉각 COP.
- UPS 손실 = IT 부하 × (1 / UPS 효율 − 1).
- 배전 손실 = (IT 부하 + 냉각 전력 + UPS 손실) × 배전 손실률.
- 기타 전력 = IT 부하 × 기타 전력률.
- 시설 전력 = IT 부하 + 냉각 전력 + UPS 손실 + 배전 손실 + 기타 전력.
- 냉각 상태 카드의 °C 수치는 실제 냉각 여유율이 아니라 랙 입구 추정 온도. 기준 온도 + 부하율 가산 + 외기 온도 가산 + 시나리오 보정.
