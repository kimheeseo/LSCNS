LS DATACENTER CAMPUS 3D - 버전업 및 20단계 개발 이력
============================================================

[최신 추가 변경: v4.8.1 · 2026-10-15]
- 첫 진입 시 시작 안내에 8구역 자동 가이드 투어를 추가했습니다.
- 전원 → 냉각 → 광케이블 단선/우회 순서로 추천 시나리오를 자동 재생하고 일시정지/중지할 수 있습니다.
- 가정값 패널을 상단에서 바로 열도록 표시를 개선하고 PUE, UPS 잔여시간, 가용성 및 광 링크 예산 계산 방식을 공개했습니다.

- 교육용 가정의 한계: UPS 잔여시간은 설정 백업 분에서 장애 경과시간을 차감하며 배터리 용량/방전율 실측이 아닙니다. 가용성은 장애 유형×이중화 등급의 가정표 조회이며 MTBF/MTTR 신뢰도 계산이 아닙니다.
- 변경 범위: LS_Datacenter_3D.html 및 버전/사용 안내와 회귀 테스트만 갱신. 2D Gold Pixel Tour, BOM 도구, Three.js 모듈 파일은 변경하지 않았습니다.
- 정적 인라인 JavaScript 구문 확인 통과. GitHub Actions 브라우저 검증과 Pages 반영은 저장소 실행 결과 확인 필요.
- 기능 시작: 첫 접속 → 안내 시작 화면 → 투어/추천 시나리오/광 네트워크 버튼. 가정값은 상단 "⚙ 가정·수식" 버튼에서 수정합니다.

[3. 신규 버전 표시 방법 / 캐시 갱신 원리]
1) HTML title 및 사이드바 표시에서 v4.7.0 코어와 v4.8.0-rc.1을 구분한다.
2) Three.js 분기는 URL의 ?engine=three로 활성화한다.
   ?engine=legacy 또는 기본 URL은 기존 렌더러를 유지한다.
3) Bootstrap은 ES import로 scene-adapter와 고정 버전의 각 *.mjs 모듈을 읽는다.
4) 이전 단계 04~18 코드 변경 시 브라우저 캐시를 피해가기 위해
   ?v=20261015-stepXX 등의 버전 Query를 모듈 import URL에 추가했다.
5) 이 릴리스는 릴리스 문서/표시 버전 갱신이며, STEP18 모듈 import 버전은 보존.
   단지 버전 문구를 바꿨다고 WebGL 실측 합격이나 하위 모델의 버전 변경을 의미하지 않는다.
6) 이후 실제 코드 수정은 새 커밋 + import query 변경 + 보호 테스트 통과 +
   단계 보고서 수정 + GitHub Pages 실제 확인 순으로 반영해야 한다.
7) 다른 프로젝트(CPO, COMSOL, 원본 DataCenter BOM, Gold Pixel Tour)는
   릴리스 스코프에서 분리한다.
