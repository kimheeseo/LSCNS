1. 도구 소개
이 페이지는 데이터센터 캠퍼스의 구역, 설비, 작업자, 전력·냉각·광통신 흐름 및 운영 장애 시나리오를 살펴보는 브라우저 기반 3D 개념 모델입니다.
실측 CAD/BIM, 제품 카탈로그, 운영 시스템과 연결된 관제 화면이 아닙니다. 표시되는 랙 수, 용량, 부하, 온도, PUE, 가용성, 링크 손실 및 시나리오 결과는 교육·설계 검토용 가정값입니다. 실제 설계나 운전 판단에 사용하기 전에 별도 검증이 필요합니다.

실행 주소
https://kimheeseo.github.io/LSCNS/DCI/DataCenter/LS_Datacenter_3D.html

2. 시작하기
처음 방문하면 5단계 사용 안내가 열립니다.
1) 구역 선택
2) 설비 살펴보기
3) 운영 시나리오
4) 흐름 표시
5) 작업자 시점

이전/다음으로 이동하고, 건너뛰기 또는 완료할 수 있습니다. 다시 보고 싶으면 상단의 “? 안내”를 선택하세요. “다시 보지 않기” 선택은 브라우저의 로컬 저장소에 보관됩니다. 저장소를 사용할 수 없는 환경에서는 안내가 다시 표시될 수 있습니다.

3. 7개 구역 이동
화면 왼쪽 구역 목록 또는 모바일 상단 구역 선택 메뉴에서 이동합니다.
- Campus: 캠퍼스 전체와 출입 구역
- Utility Yard: 변압기, 수배전, ATS, 발전기
- Cooling Plant: 냉각탑, 칠러, 펌프, CDU
- Gray Zone: UPS, 배터리, PDU, 배전
- Data Hall: GPU 랙, ToR, ODF, CRAH
- Network / MMR: Carrier, Core, Spine, Leaf, MMR
- NOC / Safety: 관제, 보안, 소방

운영 형태 선택에서 AI Data Center, 회사 서버실, On-Premises 프리셋을 바꿔 볼 수 있습니다. 프리셋에 따라 입력 가정과 지표가 달라집니다.

4. 3D 화면 조작
- 마우스 드래그: 카메라 회전
- Shift+드래그 또는 우클릭 드래그: 화면 이동
- 마우스 휠: 확대·축소
- 전체: 캠퍼스 전체 범위로 돌아가기
- 3D / 평면: 원근 3D 또는 위에서 본 평면 보기
- 지붕 켜기: 지붕 표시 전환
- 단면 보기: 건물 단면 표시 전환
- 작업자 4명: 작업자 목록과 업무 시점 열기
- 걷기: 탐방 모드 전환
- 전체 화면: 브라우저 전체 화면 전환
- 설비 검색: 이름으로 설비를 찾아 이동

모바일:
- 한 손가락 드래그: 회전
- 두 손가락 드래그: 화면 이동
- 두 손가락 핀치: 확대·축소
- “화면 조작” 메뉴를 열면 3D 보기 버튼을 사용할 수 있습니다.
기기와 브라우저에 따라 터치 동작이 다르게 느껴질 수 있습니다.

5. 설비 조사 및 내부 보기
3D 장면의 설비 또는 오른쪽 “현재 구역 설비 목록”에서 설비를 선택합니다. 오른쪽 “3D 설비 검사” 패널에서 구역, 분류, 가상 용량, 상태와 설명을 확인할 수 있습니다.
- “설비 확대”: 선택한 장비 쪽으로 카메라 이동
- “내부 보기”: 장비별 구조·배선 설명 열기
- “설비 정지”: 선택 장비를 정지 상태로 바꾸는 가상 조작

랙 검사 화면에서는 전면/후면, 도어, 서버 인출, 카세트, 포트 및 케이블 경로 등의 조작을 제공합니다. 상부 랙 구성도에서 42U 1U ToR Switch가 패치패널·카세트·서버보다 위에 놓인 것을 확인할 수 있습니다. 광 카세트를 인출하면 MPO/MTP 입력, 분배 모듈 3개, SN/MDC 출력과 카세트에서 ToR 포트까지의 청록·자홍 광 경로가 함께 표시됩니다. 화면에 표시되는 케이블·포트·장비 구성은 구조 설명을 위한 모델이며 실제 설치도나 제품 치수와 같다는 뜻은 아닙니다.

6. 작업자 4명과 작업자 시점
상단 근무 현황 카드, “업무 목록 · 시점 선택” 또는 3D 도구의 “작업자 4명”을 선택합니다.
작업자 카드를 고르면 담당 업무와 현재 상태를 확인하고 해당 작업자를 따라가는 관찰 시점으로 전환할 수 있습니다. “근접 눈높이 보기”로 시야를 조정하고 “직원 시점 종료”로 캠퍼스 보기로 돌아옵니다.
작업자 경로와 점검·순찰은 시뮬레이션 연출입니다. 실제 인력 위치나 작업 지시를 반영하지 않습니다.

7. 흐름 및 설비 상태
오른쪽 “흐름 표시”에서 전력, 냉각, 광통신을 각각 켜거나 끌 수 있습니다. 범례 색은 계통을 구분하는 시각 보조이며, 상세 구조는 설비 및 링크 패널에서 확인하세요.

8. 장애 시나리오와 이중화 비교
오른쪽 “운영 장애 시나리오”에서 시나리오를 선택합니다.
- 정상 운영
- Utility 전원 장애 · 발전기/UPS 절체
- 냉각탑 장애 · 온도 상승
- Core 네트워크 연결 장애
- 화재 감지 · 가스 소화 방출
- 액냉(DLC) 누수
- 랙 과열 · 핫스팟
- 광케이블 단선 · 우회 경로
- UPS 배터리 방전 · 발전기 기동 실패
- GPU 부하 급증 · 학습 잡 시작

재생/일시정지, 초기화, 1×/5×/15× 속도로 진행을 조절합니다. 장애 진행 단계와 설비 강조, 경고 표시 및 이벤트 로그를 확인하세요. 시나리오 단계 시간과 영향은 개념 시뮬레이션용 가정입니다.
“이중화 구성”에서 N, N+1, 2N을 선택한 뒤 “비교 실행”을 누르면 구성별 가상 결과를 비교할 수 있습니다. 결과는 실제 가용성 보증이나 설계 검증값이 아닙니다.

9. 그래프와 이벤트 로그
화면 아래 “추이 그래프 · 이벤트 로그”를 펼칩니다.
- 시계열 그래프: IT/시설 전력, 랙 입구 온도, PUE, 운영 가용성, UPS 잔여시간, 가용 전력 용량
- 이벤트 로그: 시각, 심각도, 구역, 설비, 메시지
- INFO / WARN / CRITICAL 필터
- 로그 행 선택: 관련 설비로 카메라 이동
- “로그/추이 CSV”: 로그 및 추이 데이터 내보내기

상단 “CSV 내보내기”는 설비 구성 데이터를 내보냅니다. CSV는 스프레드시트에서 열어 검토할 수 있습니다.

10. 설정, 광 네트워크, JSON 및 BOM
상단 “설정”에서 가정값을 살펴보고 변경합니다. 랙 수, 랙당 IT 전력, GPU 비율, 냉각·이중화 조건, 외기 온도, UPS 효율과 광 모듈 구성 등 설정 항목이 있습니다.
- 소규모 서버실 / 엔터프라이즈 / AI 학습 캠퍼스 프리셋
- “계산 근거 보기”: 사용 수식과 중간 계산값
- JSON 내보내기 / JSON 불러오기: 현재 가정값과 레이아웃 설정 저장·복원
- “BOM 툴로 전달”: 현재 구성을 데이터센터 설계·BOM 페이지로 전달
- “초기값 복원”: 기본 설정으로 되돌리기

상단 “광”에서 광 네트워크 토폴로지와 링크 가정을 확인하고, 모듈 방식·포트 설정을 바꿔 비교할 수 있습니다. 링크 예산 및 네트워크 값은 설정 가능한 가정값입니다. 링크 손실이나 마진은 실제 광부품 데이터시트와 현장 경로를 대신하지 않습니다.

11. 화면 품질과 문제 해결
상단 “품질” 버튼을 눌러 낮음 / 보통 / 높음으로 전환합니다. 낮은 품질은 성능이 부족한 기기에서 사용할 수 있습니다.
브라우저가 WebGL을 지원하지 않거나 사용할 수 없는 경우 3D 대신 안내창이 나타납니다. 브라우저의 WebGL 지원을 확인하거나 화면의 “2D Gold Pixel Tour 열기” 링크를 사용하세요.
페이지에서 이상 동작이 보이면 먼저 다시 불러오고, 필요하면 품질을 낮춘 뒤 다시 시도하세요.

12. 접근성 및 단축키
주요 버튼은 키보드 Tab으로 이동하고 Enter 또는 Space로 실행할 수 있으며, 포커스는 테두리로 표시됩니다. 안내 모달이 열려 있을 때는 화면 안내의 이전/다음/닫기 버튼을 이용하세요. 일부 단축키는 브라우저나 페이지 상태에 따라 동작하지 않을 수 있으므로 화면 버튼을 우선 사용하세요.
