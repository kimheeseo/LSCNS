# DataCenter UX10 — design procurement and official events

- Product requirements generated from the current BOM; quantities preserve installed versus purchased stock. Official catalog families are filtered by fiber, connector Base and documented trunk core counts. Unregistered items remain RFQ. Components are marked as components, not qualified assemblies. CSV and Excel sheets export the requirements, sources, power proof, handover items and curated events.
- Base-8 uses an MPO-12 ferrule populated 4+4; Base-12 reserves 12 physical fibers. 400G SR8 requires MPO-16; 800G DR8P supports a distinct single-MPO-16 interface family. Arbitrary Base conversion is rejected. Base-16 does not fit a standard MPO-12 center key.
- Trunk requested count rounds up to a connector Base multiple, per active segment. Packing still occurs separately within each reserved endpoint pair. Default 16F request with DR4 Base-12 becomes 24F. Default B200 plan: 512 installed uplink trunks, 12,288 trunk fibers, 101,150 m total main routes including auxiliary fabrics. Optical patch-channel lengths are displayed separately; assembly fanout remains SKU-dependent.
- PUE is an input assumption or a same-period measured energy ratio, not inferred from accelerator count. Current B200 example: 128 x 14.3 = 1,830.4 kW Compute; IT 1,920.96 kW; 38 total racks; average 50.5516 kW/rack; 32 Compute racks averaging 57.2 kW; facility 2,305.152 kW at PUE 1.2. Rack sum residual < 1e-8 kW verifies internal arithmetic, not field accuracy.
- Official events are a curated snapshot checked 2026-10-03, with local date/timezone, upcoming/past and company/type/date filters. Twelve requested companies have official source and verification status. Unpublished future dates are not fabricated. This is not a real-time scraper; update official-events.js after verifying primary announcements. Sumitomo IR calendar's original fiscal-period text has a typo, so only the explicitly listed 2026 date and generic event label are used.
- Cabling handover labels/test records are a separate procurement allowance, not priced material added twice. OOB remains direct RJ45 planning; structured horizontal cable/keystone/panel layout requires a dedicated site route plan.
