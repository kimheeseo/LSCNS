# NVIDIA Vera Rubin Platform

Source: `gpu-architecture-datasheet-vera-rubin-nvidia-us-5198950-web.pdf`

This folder adds NVIDIA data center AI factory products from the Vera Rubin datasheet as metadata-only catalog entries.

- NVIDIA Vera Rubin NVL72
- NVIDIA Vera Rubin Superchip

## Notes

- The catalog is grouped under `NVIDIA / AI Factory Platforms / Vera Rubin Platform`.
- Product descriptions and brief specs are extracted from NVIDIA's Vera Rubin datasheet.
- The source PDF is not uploaded to GitHub; the DataCenter Tool uses `catalog.json` metadata for the product cards.
