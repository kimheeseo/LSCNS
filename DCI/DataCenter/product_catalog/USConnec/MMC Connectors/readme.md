## Summary

MMC is US Conec's **Very Small Form Factor (VSFF) multi-fiber connector** platform. It uses reduced-size **TMT ferrule technology** harmonized with MT/MT-16 alignment structures and supports dense connector access with **DirectConec™ push-pull** boot technology.
