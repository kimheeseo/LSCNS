# YOFC MTP-LC Conversion Module (UDF)

This product is registered as a **URL-only catalog product** because no PDF has been uploaded to this repository.

Official source:
https://en.yofc.com/view/3031.html

Key points from the official page:
- Converts 12-core/24-core MTP trunk interfaces to duplex LC distribution.
- Duplex LC adapters are on the front; one or three MTP adapters are on the rear.
- Insertion loss: ≤0.35 dB for multimode and ≤0.65 dB for single-mode.
- Designed for UDF rack-mounted fiber optic patch panels.
- Standards: TIA/EIA 604-5-D-2007 and IEC 61754-7-2008.
