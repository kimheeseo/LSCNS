# YOFC Data Center Products

Official YOFC pages are stored as **URL-only catalog products** when no PDF has been uploaded.

Rule used by this catalog:
1. If the official page provides a **Product Model** table, every model is saved as a separate product entry using its Product Description.
2. If no Product Model table is published, the page is stored as a **Characteristics-only** entry rather than inventing a model number.
