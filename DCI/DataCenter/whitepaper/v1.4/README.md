## 사례 B 실행 재현

GitHub 저장소 루트에서 Node.js 18+ 설치 후:

```bash
node DCI/DataCenter/whitepaper/v1.4/validate_caseB.cjs
```

기대 출력: `PASS: 19 value assertions + 1 invalid schema rejection`

| 랙 수 | 2 | 계산 도출이 아닌 입력값 |
| DGX H100 서버 | 8 | 명시된 입력값 |
| GPU | 64 | 8서버 × 8GPU/서버 |
