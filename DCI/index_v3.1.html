Network / Fabric

STEP 5 · Power / Cooling
A/B feed, PDU outlet, thermal load, airflow 또는 DLC/CDU를 검증합니다.

6-2. Power Connectivity · Stage 4

서버/스위치 PSU → locking power cord → PDU-A/B → outlet/feed까지 Rack별로 계산합니다. PDU 정격과 outlet 수는 사용자 설계 가정이며, 장비 PSU/cord 수는 제품 프로파일을 사용합니다.

6-5. Cooling / Thermal Engine · Stage 10

IT 전력은 1차 설계에서 거의 동일한 열부하로 변환하여 QIT[kWth] ≈ PIT[kW]로 계산합니다. Airflow, rack cooling capacity, rear-door HX, DLC/CDU를 장비 reference와 함께 검증합니다.

참고 · GPU / Server Profile DB
GPU 자체 사양과 배포 단위를 분리했습니다. L4/L40S = GPU card, DGX H200/B200/B300 = server system, Vera Rubin NVL72 = rack-scale system입니다. L4/L40S 서버 RU·전력·NIC는 Partner Host 입력값으로만 계산합니다.
참고 · Switch / Port Mode DB
Physical cage와 logical port를 분리했습니다. 같은 OSFP 1개라도 QM9700은 2×400G, SN5610/Arista/Cisco는 1×800G 또는 2×400G, Quantum-X800 Q3400은 1 cage에서 2×800G XDR logical ports로 계산됩니다. Downlink/Uplink는 보수적으로 서로 다른 cage pool에 배치하는 segregated cage policy를 사용합니다.
