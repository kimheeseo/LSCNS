# Sources — Frontier

Primary source:
- OLCF Frontier User Guide: https://docs.olcf.ornl.gov/systems/frontier_user_guide.html

Used facts:
- 77 racks × 128 nodes = 9,856 nodes
- 4 MI250X per node
- 2 GCD per MI250X = 8 visible GPUs/node
- 4 × 200 Gbps Slingshot NICs/node
- 800 Gbps node injection bandwidth

Note:
- Another OLCF allocation page has a historical/currently inconsistent 9,408-node figure. The User Guide is used as the frozen benchmark source for this Case.
