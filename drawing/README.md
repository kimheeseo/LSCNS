2026-11-27 (KST). 외부 이미지·3D 모델 없이 기본 지오메트리로 구성한 단일 HTML 교육 도구입니다.

- [실행 (GitHub Pages)](https://kimheeseo.github.io/LSCNS/drawing/)
- [완성 HTML 전체 소스](index.html)
- [검증 코드](tests/verify.cjs)

## 구현 구조

1. 유리봉 공급 → 가열로 → 유리 직경계 → 헬륨 냉각 → 1차 도포/UV → 2차 도포/UV → 코팅/편심 검사 → 캡스턴 → 댄서 → 스풀의 10단계.
2. Three.js r128을 `https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js`에서 로드. OrbitControls는 포인터·휠·키보드 이벤트로 직접 구현.
3. CatmullRomCurve3 + TubeGeometry 섬유 경로와 미리 확보한 입자 배열. 장비는 초기화 시 생성하며 운전 조건 변경 시 정점 배열을 갱신.
4. 질량보존 직경, 허용 오차 경고, 생산 길이와 유리봉 소모 적분, 공급 맞춤 버튼.
5. 단계별 카메라, 단면, 장비 외관 반투명, 직경 강조, 라이트/다크, 모바일용 탐색 패널.

## 사용법

`index.html`을 인터넷에 연결된 브라우저에서 열거나 위 Pages 경로를 사용합니다. HTML을 로컬에서 열어도 별도 빌드는 필요 없습니다. CDN 접근이 차단되면 명시적인 오류를 표시합니다.

- 재생/일시정지, 리셋, 시간 배율 0.1–5배를 사용합니다. 시간 배율은 애니메이션과 생산 길이 적분 모두에 적용합니다. 탭을 숨기면 누적을 정지합니다.
- 인출 속도 Vf, 공급 Vp, 유리봉 직경 Dp를 독립적으로 바꿉니다. `125 µm에 맞춰 공급 속도 설정`으로 현재 Vf/Dp에 맞는 공급량을 계산합니다.
- 단계 이름 또는 3D 장비를 클릭합니다. 이전/다음으로 이동하고 단계별 보기에서 선택한 라벨을 확인합니다. 우측 설명 패널은 세로로 스크롤할 수 있습니다.
- 마우스 드래그: 회전. Shift/우클릭 드래그: 이동. 휠: 확대. 한 손가락: 회전. 두 손가락: 이동/핀치 확대. 캔버스에 포커스를 두고 방향키: 회전, Shift+방향키: 이동.
- 단면 위치를 선택하면 해당 공정 출구의 단면을 표시합니다. 코팅 단계는 UV 출구 기준입니다. 코어와 코팅 색상은 설명을 위한 구분입니다.
- 직경 ×320은 섬유의 시각적 강조입니다. ×1에서도 장비와 경로 길이는 모식 축척이며, 전체 모델이 실제 치수로 통일되는 것은 아닙니다.
- 모바일에서는 3D 아래의 `운전·단면` / `10단계 탐색`을 선택합니다. 단계 선택 시 설명 패널로 이동합니다.

## 계산과 가정

Vp 입력 단위는 mm/min, Vf는 m/s, Dp는 mm, Df는 µm입니다. 밀도 동일, 유리 손실 없음, 정상상태를 가정합니다.

```text
Df [µm] = Dp [mm] × 1000 × sqrt(Vp [mm/min] / (60000 × Vf [m/s]))
Vp,125 [mm/min] = Vf [m/s] × 60000 × (0.125 [mm] / Dp [mm])²
L [m] = ∫ Vf [m/s] dt [s]
```

| 항목 | 기본값 / 가정 |
|---|---|
| 유리봉 Dp | 50 mm (입력 25–100 mm) |
| 인출 Vf | 10 m/s (입력 0.5–20 m/s) |
| 공급 Vp | 3.75 mm/min (입력 0.02–30 mm/min) |
| 유리 Df | 125 µm, 허용 124–126 µm (경계 포함) |
| 코어 직경 | Df × 8.2/125, 기준 8.2 µm. MFD가 아닌 구조값 예시 |
| 1차 코팅 외경 | Df + 65 µm = 기준 190 µm |
| 최종 코팅 외경 | Df + 120 µm = 기준 245 µm |
| 장력 | 0.12 + 0.008 Vf + 0.0004 abs(Df − 125) [N], 교육용 식 |
| 로 온도 | 2,000 ℃, 1,800–2,200 ℃ 조절은 색상에만 반영 |
| 냉각 | 개념 온도 구배, 열유동 해석 아님 |
| 유리봉 초기 길이 | 430 mm 가정, 시각적 세로 축척 100 mm/장면 단위 |

코팅 두께 고정은 시각화용 가정입니다. 실제 코팅 공정은 수지 점도·금형·온도·압력·속도에 좌우됩니다. 순차적인 wet-on-dry 공정을 표현했으며 모든 제조 라인이 이 구성인 것은 아닙니다. 실리카는 저점도로 연화되어 인출되는 것으로 설명하며 넥다운은 정확한 유동해석 형상이 아닙니다.

입력 변경은 정상상태를 즉시 재계산합니다. 열·점도·장력 연성, 전달 지연, 직경 폐루프 제어, 편심 계측/결함 판정, UV 경화 반응, 파단, proof test는 포함하지 않습니다. 편심은 0, 스풀은 고정된 선권취 반경으로 가정합니다. 휠·입자는 방향을 쉽게 관찰하도록 감속 표현합니다. 실시간 표시는 실측 센서값이 아닙니다.

제공된 참고 그림 3장의 수직 배치 및 두 단계 코팅/UV 경화를 참고했습니다. 원본은 저장소에 업로드하거나 앱에 포함하지 않았습니다.

## 검증

### 재현 가능한 회귀 검사

의존성은 Three.js r128 하나이며 검사에서는 실제 수학·곡선·지오메트리를 사용합니다. DOM과 WebGLRenderer는 대역으로 제공하므로 GPU 렌더링 검사는 아닙니다.

```bash
curl --fail -L https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js -o /tmp/drawing-three-r128.js
node drawing/tests/verify.cjs /tmp/drawing-three-r128.js
```

2026-11-27: **13/13 PASS**. 500개 조건의 질량보존 단위 변환, ±1 µm 경계, 125 µm 공급 맞춤, 길이 적분/일시정지/5배 시간, 단계 경계/코팅 단면/초기화, 50회 반복 입력에서 지오메트리 **168개로 일정**함을 확인했습니다. 인출 속도를 10→20 m/s로 바꾸면 88.388 µm, 공급을 7.5 mm/min으로 맞추면 125 µm입니다.

### 브라우저 확인 범위

미리보기 브라우저는 WebGL 컨텍스트를 생성하지 못했습니다. 자동으로 동일 Three.js 장면을 Canvas 2D에 투영하는 CPU 호환 보기로 전환하여 공정 표시, 직경 이탈 경고, 공급 맞춤, 2차 코팅 단면, 단계 이동, 보기 토글을 확인했습니다. CPU 보기에서는 표면을 단순화하고 최대 초당 10회 그립니다. 표시되는 루프 FPS와 실제 렌더링 횟수는 구분됩니다.

WebGL GPU 재질/조명, 실제 모바일 멀티터치, 실기기 60fps는 검증하지 않았습니다. WebGL 지원 기기에서는 기본 Three.js WebGLRenderer가 사용됩니다. 이 미지원 환경에서 발생한 WebGL 생성 오류는 CPU 전환으로 처리되며, 실행 중 애플리케이션 예외 여부와는 별개입니다.

## 향후 확장 3가지

1. HCF / 멀티코어 프리폼 모드: 중공 구조, 코어 배열과 인출 시 구조 보존·홀 압력 조건을 별도 모델로 구현.
2. 직경 폐루프 제어: PID와 전달 지연, 공급/속도 변동, 실제 직경 로그 CSV 비교.
3. 공정 결합: 열전달·점도·UV 경화 모델, 편심 결함, 파단과 proof test, 스풀 적층/만권 및 생산 이력 저장.
