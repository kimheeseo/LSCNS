## 세 가지 메뉴

| 메뉴 | 기능 |
|---|---|
| **공정** | 10단계 전체 흐름도. 단계를 누르면 3D 위치·설명을 확인. `프리폼 연화·인출 애니메이션`으로 넥다운 반경이 줄고 섬유가 이어지는 장면 재생 |
| **광특성 측정** | 1. 인장 시험(DTS), 2. OTDR, 3. Power Meter 중 선택. 각기 다른 장비와 작업자의 연결·버튼 조작 동작, 결과 그래프 표시 |
| **Draw Tower** | 엘리베이터 탑승 → 상층 이동 → 프리폼 장착 → 가열·직경 측정·냉각·이중 코팅·검사·인출·장력 제어 → 보빈 권취를 보는 1인칭 가이드 체험 |

기본 화면의 번호 목록·장비 라벨은 숨겼습니다. 계산 입력, 단면, 작업자·외관 투명도, 라벨 표시 설정은 우측/모바일 하단 `운전 조건 · 상세 설정`에서 펼칩니다.

## 사용법

### 공정 흐름도와 연화·인출

`공정`을 누르면 프리폼 투입부터 보빈 권취까지 10단계가 화살표로 연결된 흐름도를 표시합니다. `프리폼 연화·인출 애니메이션`을 누르면 가열로를 확대하고, 유리 하단이 적열·연화되어 넥다운과 섬유로 이어지는 모습을 보여줍니다. 실리카의 연화·점도 저하를 개념적으로 표현한 것으로, 정확한 열유동·자유표면 계산은 아닙니다.

기존 작업자 시연은 상세 설정의 제어와 함께 유지됩니다. 상부 작업자는 호이스트·안내 손잡이로 프리폼을 정렬하고, 하부 작업자는 실걸기·보빈 연결 후 조작반으로 복귀합니다. 작업자/장비를 누르면 설명을 표시합니다.

### 측정 메뉴

| 선택 | 애니메이션 | 결과 표시와 가정 |
|---|---|---|
| **1. 인장 시험 · DTS** | 시편을 두 캡스턴 그립에 장착 → 시험 시작 조작 → 그립 간격 증가 → 시편 파단 | 하중·변위·응력 그래프. 125 µm 유리, 탄성계수 72 GPa, 표점거리 100 mm, 예시 파단 하중 50 N |
| **2. OTDR** | 커넥터 연결 → 측정 시작 → 광펄스 이동과 귀환 신호 | 5 km 구간의 개념 후방산란 파형. 2 km 위치 접속 이벤트, 편도 접속손실 0.7 dB, 섬유 손실 0.2 dB/km 가정 |
| **3. Power Meter** | 광원·파워미터 연결 → 광원 버튼 → 파워미터 버튼 → 출력 읽기 | 기준 −3.0 dBm, 수신 −3.8 dBm = 약 416.9 µW, 삽입손실 0.8 dB의 예시 |

인장 시험은 기계적 특성 시험입니다. 요청된 DTS는 동적 인장강도(Dynamic Tensile Strength) 시험으로 표시했습니다. 파단 하중 50 N은 시연 가정이며 합격 기준이나 특정 제품의 보증값이 아닙니다. 코팅층의 하중 분담, 환경·하중 속도에 따른 피로, Weibull 강도 분포와 proof test는 구현하지 않았습니다.

OTDR 파형은 왕복 감쇠와 반사 이벤트를 개념적으로 그립니다. 표시한 광 이동은 감속 시연이며 실제 광속·데드존·펄스 폭·장비 보정 계산을 재현하지 않습니다. 광원과 파워미터를 이용하는 삽입손실 측정과 OTDR은 별도 장면입니다. 모든 결과는 시뮬레이션 예시로, 실제 장비를 연결하거나 계측 데이터를 수집하지 않습니다.

각 측정은 선택 즉시 시작합니다. `일시정지`와 `리셋`은 선택한 시험에 적용되며, `시험 선택`에서 다른 시험으로 이동합니다.

### 1인칭 Draw Tower

1. `Draw Tower`를 누르면 승강기 안의 1인칭 시점으로 들어갑니다.
2. `상층으로 이동`을 누르면 문이 닫히고 상부 작업대로 상승합니다.
3. 도착 후 `프리폼 장착`을 누르면 장갑을 낀 손과 함께 반입·정렬·하강을 관찰합니다.
4. 엘리베이터를 타고 내려가며 퍼니스에서 보빈까지 각 공정을 봅니다. 마지막에는 보빈 가까이로 이동해 권취층 성장을 관찰합니다.
5. `체험 다시 시작` 또는 `체험 종료`를 선택합니다.

경로를 따라 움직이는 가이드형 1인칭 체험입니다. 드래그/터치 드래그로 시선을 움직일 수 있으며, `일시정지`가 이동과 생산 동작을 함께 멈춥니다. 상세 설정의 시간 배율 0.1–5배도 적용됩니다. 실제 작업 표준, 설비 CAD 치수, 실제 승강기 속도는 재현하지 않습니다.

## 계산과 스케일

유리 직경은 밀도 동일·유리 손실 없음·정상상태를 가정하여 계산합니다.

```text
Df [µm] = Dp [mm] × 1000 × sqrt(Vp [mm/min] / (60000 × Vf [m/s]))
Vp,125 [mm/min] = Vf [m/s] × 60000 × (0.125 [mm] / Dp [mm])²
권취 길이 [m] = ∫ Vf [m/s] dt [s]  (보빈 연결 이후)
인장 응력 [Pa] = F [N] / (π × (125e−6 [m])² / 4)
변위 [mm] = (응력 [GPa] / 72 [GPa]) × 100 [mm]
광파워 [µW] = 10^(광파워 [dBm] / 10) × 1000
삽입손실 [dB] = 기준 광파워 [dBm] − 수신 광파워 [dBm]
```

| 기본 항목 | 값 / 모델 |
|---|---|
| 프리폼 직경 / 공급 | 50 mm / 3.75 mm/min |
| 인출 속도 / 유리 직경 | 10 m/s / 125 µm |
| 유리 직경 허용 범위 | 124–126 µm, 경계 포함 |
| 예시 코어 직경 | Df × 8.2/125, 기준 8.2 µm. MFD가 아닌 구조값 |
| 1차 / 최종 코팅 외경 | Df + 65 / Df + 120 µm, 기준 190 / 245 µm |
| 장력 | 0.12 + 0.008 Vf + 0.0004 abs(Df−125) [N], 교육용 식 |
| 로 온도 / 냉각 | 기준 2,000 ℃ / 개념 온도 구배 |
| 길이·직경 축척 | 장비·경로는 모식 축척, 섬유 직경은 기본 ×320 강조 |

프리폼 시연은 0–6초 반입/투입, 6–10초 연화/넥다운, 10–28초 초기 실걸기, 이후 연속 권취입니다. 1인칭 체험에는 그 전에 별도의 승강기 이동·상층 작업자 시점 진입이 추가됩니다. 시연 시간은 실제 기동 시간이 아닙니다. 권취층 성장은 시각적으로 과장하며 실제 보빈 용량을 계산하지 않습니다.

## 구현과 검증

외부 이미지·모델·폰트 없이 기본 지오메트리로 구성했습니다. 제공된 공정 그림 3장의 수직 배치를 참고했으며 원본 이미지는 포함하지 않았습니다. CDN 의존성은 다음 하나입니다.

`https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js`

OrbitControls는 포인터 이벤트로 직접 구현했습니다. 섬유 경로는 CatmullRomCurve3 + TubeGeometry, 흐름·열연화는 사전 할당한 정점/입자 배열을 갱신합니다. 시험 장비, 작업자, 승강기와 장갑 손도 초기화 시 생성하며 재생 중 새 지오메트리를 만들지 않습니다. 탭을 숨기면 시뮬레이션 시간을 멈춥니다.

```bash
curl --fail -L https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js -o /tmp/drawing-three-r128.js
node drawing/tests/verify.cjs /tmp/drawing-three-r128.js
```
