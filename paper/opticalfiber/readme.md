- 참고 영상: [YouTube](https://www.youtube.com/watch?v=AVo-YAsVVFU&t=949s)

- [High_density_optical_cable_with_ultra_low_loss,_large_effective_area_ITU_T_G_654_E_Optical_fiber.ipynb](./High_density_optical_cable_with_ultra_low_loss,_large_effective_area_ITU_T_G_654_E_Optical_fiber.ipynb): 발표의 G.654.E/G.652.D SNR 곡선과 기준점을 비교합니다.
